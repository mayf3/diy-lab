# HachimoDock 采购研究方向修正（2026-11-09）

## 结论先行

官方固件已将原版屏幕目标锁定为 **WLK2802MIPI-15P / ST7701S**，而不是 NV3049：

- 分辨率：480×640（固件逻辑 framebuffer 旋转为 640×480）
- MIPI-DSI：**1 data lane**
- lane bitrate：**800 Mbps**
- BSP 注释：`WLK2802MIPI-15P/ST7701S uses 1 data lane`
- 官方代码还给出屏幕复位 GPIO27、背光 GPIO26、MIPI PHY LDO 通道 3 / 2.5V；这些是主板侧控制信息，不等于屏幕连接器的全部电气规格。
- ST7701S vendor init table 已在官方 C 文件中找到；包含 page 切换、gamma、`0x11` sleep-out（120ms）、`0x29` display-on、`0x35` TE 等命令。不能把另一块 ST7701S 屏的初始化表直接套用。

## 屏幕渠道与规格核验

### 首选渠道：Thorb HachimoDock 复刻套件

链接：<https://thorb.com/en/kits/hachimodock-esp32p4-v2>

页面 BOM 明确列出：

- 无触摸：`2.8-inch 480×640 IPS MIPI-DSI display (no touch)`，model `WLK2802MIPI-15P`，标价 ¥75，套装价 ¥69；当前 `inStock=0`。
- 触摸版：`2.8-inch 480×640 IPS MIPI-DSI touchscreen (matching front case included, no screen bezel needed) WLK2802MIPI-15P`，套装价 ¥78（页面搜索摘要曾显示 ¥88 的标价/触摸+前壳选项，以下单页实时显示为准）；当前同样缺货。
- 页面产品结构化数据还写明屏幕为 2.8-inch IPS、480×640、MIPI-DSI；整套声学规格写的是 8Ω 1W，不应反推单独扬声器 SKU。

**采购结论：**这是目前找到的最接近原版、型号可追溯的购买渠道，但当前缺货，不能当作已可下单 SKU；应向 Thorb/原作者询问补货时间、V2 版本、实物照片、15P FFC 方向/长度、背光供电和触摸 IC。

### 机械尺寸、连接器与排线

公开检索到的 WLK2802MIPI-15P/Olimex MIPI-LCD2.8 资料给出模块外形约 **65×46.2 mm**、15-pin FPC；Olimex 的 ESP32-P4-DevKit 软件说明默认支持 WLK2802MIPI-15P-V2。该尺寸/标准 15P 资料尚未替代卖家原始机械图，采购前仍要拿到同一 revision 的 datasheet 或实拍尺寸图。

目前不能确认：

1. 15P FFC 的 A/B 面、触点朝向和实际长度；
2. 屏幕端 15P 与 HachimoDock PCB 端所谓 22P 评论记录之间是否存在转接板/不同 revision；
3. 背光 LED 的额定电流、供电电压及是否由屏模组板载限流；
4. 触摸版的触摸 IC、触摸 FPC 是否独立。

因此原 BOM 的 22P/0.5mm FFC 不再可直接采购，B10 已改为 HOLD。**接口脚数相同不构成兼容证明。**

### NV3049 与其他 ST7701S 屏幕的降级结论

之前查到的 NV3049、20P ST7701S、2-lane 480×640 模组全部降为：**需修改固件/可能需要转接的替代方案**。即使分辨率和 ST7701S 名称相同，也至少存在 lane 数（1 vs 2）、FPC pinout、时序、初始化表、背光和外形差异；不能标记为原版直接兼容。

## 键帽核验

官方 PCB 轴型号 `CPG135001D01 / C400229` 应按 Kailh **PG1350 / Choc V1** 处理。Choc V1 的键帽接口是顶部两条平行插脚（two-prong/two-leg），不是 MX/BOX 的十字杆；Choc V2/1353 的标题不能证明兼容。

- 优先渠道：PandaKB Choc V1 键帽页 <https://pandakb.com/shop/parts/keycap>，页面明确写 Choc V1 专用 two-prong stem；价格为海外页面价，运费/结算价未核实。
- 国内检索到“猪鼻子1350/十字1353/Choc V1V2”混售约 ¥13.5 的结果，但标题同时混用 1350 和 1353，尚未取得键帽底部照片和实际 SKU，不能采购。
- Thorb 套件有自制/打印键帽选项，但页面未给出 PG1350 底部结构证据，不能代替专用键帽核验。

B11 已保持 **HOLD**：先让卖家提供底部照片、明确 `PG1350/Choc V1`，并用 1 枚样品核对外壳键孔高度/间隙。

## 扬声器核验

微雪官方页面确认 ESP32-P4-WIFI6 板载 **ES8311 Codec + NS4150B 功放**，板上扬声器口为 MX1.25 2P，商品文档标称支持 8Ω 2W。NS4150B 公开数据则以 5V/4Ω、THD=10% 约 2.8W 为典型最大指标；8Ω负载的实际最大输出不能从“3W 功放”或接口标注直接推导。

因此：

- 不能把 2030/4230 8Ω扬声器直接代替原版 2011；
- 仍缺原版外壳净空间、2011 本体厚度/长宽、接头线长、阻抗实测和原作者确认；
- Thorb 整套页面写 8Ω 1W，只能作为套件级线索，不能证明 HachimoDock 原版 2011 SKU。

B06 已改为 **HOLD**，待原作者或外壳/装配证据闭环。
