## 门禁检查

- **PASS** — 输入适配器容量（常规最坏场景 ×1.5 ≤ 3A）：常规最坏 1126.0mA ×1.5 = 1689mA ≤ 3000mA
- **PASS** — 设计最坏并发 ≤ 输入轨容量：最坏 2512.9mA ≤ 3000mA（留 0 余量——用软件策略禁止常规触发）
- **PASS** — LED 轨容量 ≥ 软件帽后最坏：Magic 灯效 480mA ×1.5 = 720mA ≤ 1600mA
- **PASS** — 3V3 轨容量 ≥ ESP32 + 麦克风：351mA ≤ 500mA
- **PASS** — USB-C 连接器额定 ≥ 3A：标准 16pin 板载 USB-C 插座额定 5V/5A（选型轮锁定型号）
- **PASS** — 适配器协议：仅 5V，无 PD 协商需求：外置 5V/3A 认证适配器 + CC 脚 5.1kΩ Rd（UFP 默认档）；产品定位不含电池快充

## 结论

- 常规最坏并发 1126.0mA @5V，3A 适配器裕量 ×2.66。
- 设计最坏并发（全白灯+满音量+满载）接近 3A 上限：**软件策略强制**（亮度≤60%、音量≤1W），
  硬件轨按最坏校核不烧毁，但两帽策略写入 M2 状态机（Magic 状态限音量）。
- 第一版不集成锂电池，外置合规 5V/3A USB-C 适配器（产品定位不变）。
