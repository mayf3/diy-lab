# Space Buddy Deck R1 · 产品与视觉规格（G0 冻结）

**状态：视觉方向已冻结（2026-11-27，发起人确认）；工程尺寸与制造未冻结。**
本文是 R1 的产品权威定义；与 [revision-r1-usb-hid.md](revision-r1-usb-hid.md)（USB HID 路线）
和 [interface-contract.md](interface-contract.md)（引脚与装配取证）配合使用。

## 1. 产品定义

- **名称**：Space Buddy Deck R1
- **形态**：宇航员太空舱风格的 2×2 四键 USB 快捷键盘
- **使用方式**：USB-C/Micro（OTG 口）连电脑即插即用，按键发送 F13–F16；
  无需安装任何常驻程序；UART 口仅用于烧录与维护
- **用户最后动作**：插接开发板、拧螺丝、连接 USB；键帽可自行拆卸更换

| 元素 | 规格 |

## 4. 电气与固件（引用 R1）

- 按键：GPIO4–7（J1.4–7），常开按下接地，内部上拉，35 ms 去抖
- 按键输出：USB HID F13/F14/F15/F16
- 供电：OTG 口单口供电（官方推荐方式之一）；UART 口保留烧录
- 详见 [revision-r1-usb-hid.md](revision-r1-usb-hid.md) 与 `firmware-hid/AgentButtonDeckHID.ino`（草稿）

## 5. 机构待定项（G1 重点核查）

大键帽（约 24–30 mm 方形）的稳定按压是 R1 的关键机械风险：
普通 6×6 轻触开关轴面小，大键帽直接焊在开关上会倾斜、卡滞。
机构比较与推荐见 [g1-button-mechanism-comparison.md](g1-button-mechanism-comparison.md)。

## 6. 制造路线

1. 嘉立创 EDA 设计载板 PCB（四键 + 双排插座 + 布线）。
2. 嘉立创 PCB 制造；PCBA 代焊范围 = 四键开关 + 双排插座全部焊脚（主板由原厂焊接）。
3. 外壳优先嘉立创 3D 打印（树脂/尼龙按预算），P1S 用于原型试装与个性化件。
4. 报价、下单、付款由发起人本人完成；Agent 仅准备制造资料与验收记录。
