# G1 候选：静音段落轴三款比较（样轴采购建议）

**状态：候选筛选（2026-11-27）。参数来源 = 键盘社区公认资料，标注「待核实」；未取得样轴前，不冻结 SKU、键帽尺寸或 PCB footprint（发起人 G1 约束）。**

发起人约束（已记录于 models-r1.md）：`tactile-light`（轻柔段落感）+ `quiet`（安静）；
优先静音段落轴；比较维度 = 初始/触发压力、段落轻柔度、触底与回弹声音、24–30mm 键帽稳定性、嘉立创插件代焊能力。

## 三款候选（参数均为「资料核实→待核实」等级，下单前以卖家页/实测为准）

### 候选 1：Gazzew Boba U4T（TTC 代工，静音段落标杆）

**型号命名警示（2026-11-27 增补）**：Gazzew Boba 系列中 **U4T = 静音段落（T = tactile）**，
**U4（无 T）= 静音线性**——后者不满足 `tactile-light` 段落偏好，仅可作为声音对照样，
采购时以商品页「tactile」字样为准，勿凭「U4」简称下单。

| 维度 | 资料（待核实） |
| --- | --- |
| 类型 | 静音段落（硅胶阻尼垫触底+回弹） |
| 力度档 | 标准 62g（55g 亦常见）；45g/50g 轻弹簧档为部分海外商家货源，**存在性待卖家页核实**——不得按社区印象直接下单 |
| 触发/触底 | 触发约 45–55g 区间；总行程 ≈3.6mm（比标准短） |
| 段落感 | 圆润明显、不涩手——社区公认的静音段落标杆 |
| 声音 | 触底/回弹均有硅胶垫吸收，"闷弹"声，办公级安静 |
| 引脚 | 5-pin PCB mount（3-pin 版本也存在，下单时确认） |
| 装配 | TH 直插，嘉立创插件工序常见能力； boutique 开关需确认代焊覆盖 |
| 购买 | 海外店（kebo.store / thoccestore 系）或淘宝代理；现价待核实 |

### 候选 2：Zilent V2 65g（Zeal PC，高端静音段落）

| 维度 | 资料（待核实） |
| --- | --- |
| 类型 | 静音段落（阻尼触底） |
| 力度 | 65g（**偏重**——与 tactile-light 目标相反方向，仅作对照） |
| 段落感 | 圆润、浦发感低 |
| 声音 | 同级静音表现 |
| 引脚 | 5-pin |
| 装配 | TH 直插 |
| 购买 | zealpc.io 海外直购，价格高（约 $1.5–2/键） |

对照结论：**若追求"轻柔"，65g 档不占优**；候选 1 的 45–50g 档更贴合 tactile-light。

| 维度 | 资料（待核实） |
| --- | --- |
| 渠道 | 淘宝/立创易购，国内现货、便宜、补货快 |
| 已知厂商线 | 凯华（静音系列）、佳达隆、TTC、高特（Outemu）均有静音产品线；**"静音+段落"的具体型号必须逐个查 datasheet/实测，不能凭"茶轴/静音"名称推定** |

## 样轴建议（下一动作，购买由发起人本人执行）

| 款 | 数量 | 预算口径 |
| --- | --- | --- |
| Gazzew Boba U4T（62g 标准档；卖家页确有 45g/50g 轻档则加购一颗对比） | 4 颗 | 海外店约 $3–5/4 颗 + 运费 |
| 国产静音段落（凯华/佳达隆/TTC/高特 任一可买型号） | 4 颗 | ≈¥5–20 |
| （对照）Boba U4 静音线性 | 2 颗（可选） | 仅听声音对照，不做手感定档依据 |
| （对照）Zilent V2 65g | 2 颗（可选） | 海外 |

到货后实测四个维度：初始/触发压力手感、段落轻柔度、触底与回弹声音（录屏对比）、
装上打印键帽（MX 十字）后是否倾斜卡滞。结果记入 G1 定档记录。

## 决策路径
