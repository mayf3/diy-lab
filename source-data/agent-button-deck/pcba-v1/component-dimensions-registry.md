# 实物尺寸统一登记表（G2-2 · 2026-11-28）

**用途：开发板 / 机械轴 / 排母 / PCB 载板 / 插头等所有实物尺寸的唯一登记处。**
**纪律：来源三态——`官方文档`（数据手册/图纸标注）/ `官方图纸估读`（按比例读数，须实测）/ `实物测量`（卡尺实测，最高级）/ `标准推算`（公称外廓+公差）/ `待定`。
未经实测的尺寸一律不得冻结；「图纸估读」永远不能改标为「实物测量」，除非真的量过。**
CAD 参数化文件（`cad/g2-case-r1.py`）与 dims.json 引用本表；每次实测后回填并重跑几何检查器。

## 回填流程

1. 实物到手 → 卡尺/游标测量 → 本表「来源等级」升为 `实物测量` 并记日期与工具；
2. 同步更新 `cad/g2-case-r1.py` 参数与 dims.json → 重跑建模 + `check_case.py`（必跑）；
3. 若实测与估读偏差 > 0.5mm：检查器必须复跑，受影响的下游尺寸（开孔/包络/裙壁）逐项重判。
