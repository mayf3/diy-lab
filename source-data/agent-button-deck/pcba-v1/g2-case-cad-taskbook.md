## G2-1 分色分盘输出（借鉴 HachimoDock「分件分色，零喷涂」）

| 打印件 | 颜色 | 备注 |
| --- | --- | --- |
| 主体上壳（正面宇航员/舷窗所在件） | 奶油白 #fff9e9 系 | 浮雕装饰随本体一次成型 |
| 底座（包覆主体下缘 + 螺柱/脚垫） | 薰衣草紫 #b7a4e3 系 | 承载 PCB，与主体可拆卸（螺丝） |
| 键帽 ×4 | 珊瑚橙 / 星空蓝 / 薄荷绿 / 暖黄 | 顶部平面留图案区（浮雕或贴纸槽，G2-3 定） |

- 每件单独成盘（单色 PLA）；**四色键帽打印路线（分盘 / AMS / 贴纸 / 嘉立创多材料）是发起人 G2 前决策项**，CAD 侧保持「每键帽独立零件」以兼容全部路线。
- 键帽内腔先用 **MX 十字占位特征**（轴体 SKU 未定档，不画最终孔）；外轮廓按视觉规格 24–30mm 方形占位。

## G2-2 固定与接口（借鉴 HachimoDock「M2.5 + 热熔铜螺母」）

- 底座 4×M2.5 螺柱，热熔铜螺母（M2.5×4×3.5 级，参考 HachimoDock B09 用料）；螺柱孔公差标注 ±0.1–0.2mm，背面避空压入深度。
- PCB 支承面：DevKitC 插 2×排母 + 四键 TH 焊脚受力，底座承载面不得悬空（M2 约束）。
- 双 USB 开孔：OTG（键盘信号）+ UART（烧录维护）两口；**孔位/孔宽按 DevKitC 到货实物测量定稿**（见 [g1-devkitc-sku-check.md](g1-devkitc-sku-check.md) 下单前核实第 3 条），不得按网页图比例。
- 壁厚 ≥2mm；配合间隙 0.3–0.5mm；键帽行程避空 ≥ 轴体总行程 +0.5mm（行程参数随轴体定档填入）。
- 底部防滑脚垫槽 ×2（G0 规格），螺丝孔不外露。

## G2-3 装饰与产品语言

- 宇航员头像 / 舷窗 / 星星：优先**浅浮雕**（凸起 ≤0.6mm，单色件随本体成型）；备选贴纸槽。浮雕深度与打印方向在首版切片验证，不做双色喷绘。
- 键帽图案区：顶部平面预留（火箭/星球/星星/月亮），实现方式随四色打印路线决策（浮雕 or 贴纸）。
- 正面 / 侧面 / 背面语言统一：正面装饰件=上壳本体；侧面键帽-舷窗视线关系按 concept-r1 布局比例参数化（不照抄像素比例）。

## 验证与验收（进入 G5/G3 的条件）

1. FreeCAD 干涉检查：键帽行程包络 × 键孔、DevKitC+排母包络 × 上下壳、USB 插头包络 × 开孔——零干涉报告落盘。
2. 试装小样：P1S 打印底座缩比件 + 键帽单件，验证 M2.5 螺柱/热熔螺母配合与键帽装拆。
3. G5 板壳联合：`case-r1.step` 与 PCB 板框（G4 产物）对齐检查。
4. 发起人视觉评审：浮雕装饰「像不像太空舱」人工确认（M4 口径，不数学化）。

## 明确不做

- 不提前冻结 PCB footprint / 键帽孔最终尺寸（轴体 SKU 未定档）。
- 不引入摇杆、屏幕、灯光等参考工程元素（不在 R1 规格）。
- 不复制任何第三方外壳几何（HachimoDock 外壳为 SDFL-PPO，仅限其平台打印）。
