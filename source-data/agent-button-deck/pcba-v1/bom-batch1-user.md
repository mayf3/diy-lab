| 项 | 内容 |
| --- | --- |
| 买什么 | **Gazzew Boba U4**（静音段落轴，白壳/黑壳均可，62g 档优先）× 4 颗 |
| 再买什么 | 国产静音段落轴 × 4 颗（淘宝搜「静音段落轴」，凯华/佳达隆/高特任一标注"静音+段落"的型号） |
| 参考链接 | RNDKBD（海外）：https://rndkbd.com/collections/bfcm/products/gazzew-u4-boba-switches ；淘宝搜「Boba U4 静音」 |
| 大概花费 | 海外店约 $3–5/4 颗 + 国际运费；国产约 ¥5–20；**以页面实时价为准** |
| 兼容性依据 | 静音段落（硅胶阻尼）+ MX 标准 5 脚直插，就是普通机械键盘那种轴 |
| 替代 | 若 U4 缺货：Zeal Zilent V2 62g，或纯国产静音段落 |

**下单前请在卖家页核对 3 件事（30 秒）**：
1. 名称写的是 **U4** 且含「silent / 静音」（⚠️ U4T 不是静音轴，别买错）；
2. 弹簧力度 62g 上下（45g/50g 更轻，有就顺手加 1 颗对比）；
3. 有实物图片（不是渲染图）。

## ② 开发板（插上去就能用的那种）

| 项 | 内容 |
| --- | --- |
| 买什么 | **ESP32-S3-DevKitC-1-N8R8** × 1 块，**排针已焊好的版本** |
| 参考链接 | 乐鑫官方页推荐渠道：https://www.aliexpress.com/item/3256803793464226.html ；国内可搜淘宝「ESP32-S3-DevKitC-1 N8R8」比价 |
| 大概花费 | 官方参考 $17 级；国内渠道通常 ¥60–90 + 运费；**以页面实时价为准** |
| 兼容性依据 | 乐鑫官方开发板；4 键 USB 键盘用 8MB Flash + 8MB PSRAM 绰绰有余；排针插我们设计的底板，不需要焊接 |
| 替代 | N16R8（内存更大，只在 N8R8 缺货时买） |

**下单前核对 2 件事**：
1. 型号末尾是 **N8R8**（不是 N8R2/N16R8）；
2. 图片里板子两排针脚**已经焊好**（没有焊好的话需要另外找师傅焊，我们先不用那种）。
