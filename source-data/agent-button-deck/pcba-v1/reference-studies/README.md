# 参考工程研究目录约定

本目录存放 Space Buddy Deck 的**设计参考库**：对第三方硬件工程的「怎么做」研究。
参考研究是 G1 之前的输入，**不新增门禁**，也不阻塞 G1/G2 推进。

## 每个参考工程一份 `<name>-study.md`，必须包含

1. **资料审计表**：来源/版本/许可/查看日期；下载过的原文记 SHA256（原文存临时目录，不入仓库）。
2. **六方面研究**：A PCB 设计 / B 机械结构 / C 外观设计 / D 制造交付 / E 设计验证 / F 成本工艺；每条标注证据等级（资料核实 / 计划或推测 / 未取得）。
3. **四列对照表**：参考项目做法 / 可借鉴之处 / Space Buddy 应用 / 不采用的部分。
4. **五项输出**：最值得借鉴的实践、Space Buddy 需改变的设计、不应照搬的部分、工作台改进、对 CAD/PCB/制造任务书的影响。
5. **尚待核实清单**：不阻断 G1/G2 的开放问题。

## 红线

- 不把第三方工程文件（原理图/PCB/STEP/STL/3MF/视频等）复制进本仓库；只登记来源、版本、许可、哈希。
- 许可边界逐字记录（特别是「仅限平台打印」「非商业」「禁止转载」类条款）。
- 不据参考研究直接下单；采购永远走发起人本人批准流程。

## 与工作台的连接

`workbench/catalog.json` 的项目条目 `reference_studies` 区引用本研究（许可/借鉴模式/对应任务/完成度/待核实），由 `build_data.py` 透传到 `web/workbench.json` 展示；`workbench/test_consistency.py` 校验字段完整性。
