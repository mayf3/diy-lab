## 1. 六方面研究结论

### A. PCB 设计

- **架构 = 成品开发板 + 载板**：微雪 ESP32-P4-WIFI6(-M) 成品板插 2 只 2.54mm 1×20P 排母；载板只承担屏幕 FPC 座（22P 0.5mm）、3 键、摇杆（YA13S，14P 直插）、扬声器 1.25 端子。主控/射频/电源等复杂部分全部由原厂焊接的成品板承担，载板保持以插件为主的简单工艺。（资料核实：正文 BOM 与 RS5）
- **原理图与 PCB 对应关系存在已知缺口**：SCH_V1.2（2026-10-30 更新）与已发布 PCB_V1.2 有网表差异警示，原作者口径「以已发布 PCB 为准」（主仓 BK3，open）。**教训：原理图/PCB 版本错位时，制造以 PCB 为准，差异显式登记为疑点，不做静默自动更新。**
- **嘉立创可制造文件交付方式**：主工程页不直接提供 Gerber/BOM/CPL/STEP 下载（各栏「暂无数据」），依赖「打开设计图」在线查看 + 附件 .epro2；下单时从工程导出。替代屏工程示范了更完整的交付：.epro2 + BOM 全带立创编号 + 3MF。（资料核实）
- **未取得（留作疑点）**：主 PCB 层数/板厚/板框尺寸；封装库细节；主工程 .epro2 内容（需登录且受许可约束，未下载）。

### B. 机械结构

- **上下壳拆分**：上壳（含 3 键孔）+ 底壳两件主体，另有摇杆盖板/摇杆杆/摇杆帽独立小件（3 盘分色打印）。（资料核实：RS3）
- **PCB 固定 = M2.5×6 盘头螺钉 ×2 + 热熔铜螺母 M2.5×4×3.5 ×2**（主仓 bom.csv B08/B09）：仅两点固定，配标准热熔螺母压入打印壳——零件数最少化的固定方案。
- **元件-壳体配合**：原版屏为 2.5D 曲面圆玻璃屏直接嵌壳；换平面替代屏时**必须**另加亚克力/3D 打印外框（附件有尺寸图），且触屏/非触屏外壳 3MF **两版不可混用**。（资料核实：RS1/RS4）
- **键轴-键帽-壳孔配合是真实翻车点**：官方正文写「Kailh BOX 轴、外形一致即可」，BOM/PCB 实为 CPG135001D01（PG1350 低轴、双脚键帽接口）——两者封装完全不同，主仓 BK4 至今 open。壳体键孔按哪个轴打，直接决定键帽能不能装。（资料核实 + 主仓疑点）
- **多材料/多颜色 = 分件分色**：外观三色全部来自零件本身的打印料色（白壳/黑底/橙帽），零喷涂、零二次处理。

### C. 外观设计

- **辨识度核心是屏幕内容**（桌面宠物 UI），硬件造型极简；所有元件（扬声器双面胶贴底壳、FPC 内走线）完全隐藏于壳内。（资料核实）
- **装饰即零件**：橙色摇杆帽是独立打印件——装饰元素直接做成带色的结构件，不依赖涂装。
- **产品语言三分**：上白（操作面）/下黑（承托面）/彩色点缀（输入件帽），正面/侧面/背面语言统一。
- 对 Space Buddy 的映射：我们的装饰（宇航员头像、舷窗、星星）是印刷/浮雕，不承载结构；「装饰零件化」模式直接支持四色键帽方案——**每颗键帽就是一个独立色件**。

### D. 制造交付

- **工厂真实承接**：PCB 打样（嘉立创）；转接板 PCB（嘉立创，BOM 带立创编号可直接配单）；外壳 3D 打印（嘉立创「一套外壳几十块」或自打印 P1S 3.2–3.3h）。**页面无任何 SMT 说明**——结合 BOM 结构（开发板原厂焊 + 载板插件件），推测载板走插件为主（计划或推测，未证实）。
- **作者自做步骤**：排母/轴体/摇杆插件焊接、热熔螺母压装、屏 FFC 穿线与装配；装配说明 = 图文步骤 + 附件自录教程视频 .mp4（工厂资料之外的补充）。
- **与 Space Buddy 模式互证**：「模块原厂焊 + 载板代焊范围 = 插件件」正是我们 R1 的 PCBA 代焊范围声明（DevKitC 原厂 + 四键 + 双排插座）。

### E. 设计验证

- **该工程公开资料暴露的 4 个 open 疑点全部是「跨版本/跨文档不一致」类**：BK1 silicon 版次（固件包选错变砖风险）、BK2 屏 FFC 15P/22P 记录冲突、BK3 SCH/PCB 网表差异、BK4 轴封装文字冲突。无一例外印证本仓治理重点（版本一致性/封装映射/变更传播/制造包完整性）——**不需要为它新增定理，它本身就是反例教材**。
- **制造包完整性反例**：主工程结构化 BOM 栏空、3D 模型栏空，靠正文文字 BOM 与附件补偿——机器可校验的成套制造包缺失，会把核对成本转嫁给每个复刻者。
- **装配顺序含版本分叉**：「先确认屏幕方案，再打印和装配」——屏幕方案决定外壳版本，选错即外壳报废。与我们的「轴体定档 → 键孔定稿 → 才画 PCB」同一依赖形态。
- 完整性正面示范：替代屏工程用「两版 3MF 不可混用」显式声明版本互斥，防止下游错配。

### F. 成本与工艺

- **复刻成本 ¥150**（页面文字，历史口径，未拆解；主控+屏占绝大部分）。（资料核实=该声明存在；数值本身无法拆解验证）
- 正文 BOM 参考价（2026-11-27 查看，**全部是官方参考价，非成交价；现价未知**）：主控板 ¥81.15 起；主推屏 ¥65；备用触屏 ¥40 / 非触屏 ¥22（均需转接板）；摇杆 ¥3.54 起；轴 ¥12.7 起/组合；键帽 ¥9.9/10+ 个；扬声器 ¥4.50；排母 ¥0.17/个；转接板工程 ¥12；外壳打印「几十块」。
- 主仓 bom.csv（2026-11-08/09 调研）已把 B01–B14 逐项标 HOLD/CHECK——**价格口径三分类（历史/当前/未知）在主仓已实践，本研究沿用**。

## 3. HachimoDock 最值得借鉴的五项工程实践

1. **成品开发板 + 简单载板架构**：复杂部分（SoC/射频/电源）由原厂焊接的成品板承担，自设计部分压到全插件载板——把嘉立创 PCBA 的工艺风险和费用都压到最低。R1 路线与之同构，此互证提高信心。
2. **分件分色打印实现多色外观，零喷涂**：三个打印盘三种料色，装饰元素（摇杆帽）本身就是带色结构件。R1 的四色键帽/双色壳体可直接套用，砍掉全部表面处理工序。
3. **替代件适配工程模式**：主推屏缺货时，作者发布独立「转接板工程」——转接 PCB（BOM 全带立创编号）+ 配套新壳 3MF + 「两版不可混用」版本互斥声明。这是「元件 EOL/替代」的标准化响应模板。
4. **BOM 全带立创编号 + 工厂生态闭环**：每个物料可直接在嘉立创商城按编号配单，从设计到下单零转译。降低「资料→采购」的出错率。
5. **疑点结构化登记与版本漂移监控**：主仓 sources/blockers CSV（open→closed 需证据 + 90 天复核）+ 本次实测 21 天版本漂移——证明「登记 + 定期复核」能抓到真实变化。

## 4. Space Buddy 需要改变的设计 / 不应照搬的部分

### 4.1 需要改变（新增待决策项）

1. **键帽四色的打印工艺路线必须在 G2 前定档**：分件分色（4 键 4 色各自成件，P1S 分盘或 AMS 逐色）vs 统一底色+图案贴纸（spec 已预留贴纸槽）vs 嘉立创多材料打印。HachimoDock 的 3 盘分色是 3 色小批量的可行样本，但 4 色小件分盘的时间成本要实测。→ 已加入工作台 decision_items。
2. **制造资料交付形态升级**：从「工程文件 + 说明文档」升级为「成套制造包」（Gerber/BOM(带 LCSC 编号)/CPL/STEP/3MF/装配说明/许可页），G6 用检查清单机器校验——主工程「BOM 栏空」是反面教材。
3. **装配说明须声明版本分叉依赖**（「先定 X 再打壳」形态）：R1 的对应分叉是「轴体定档 → 键帽孔/壳键孔定稿」，必须写进 G2/G4 任务书与装配说明开头。
4. **BOM 行强制挂 LCSC 编号 + 查看日期**，让 G7 下单零转译。
5. **上游/工具版本定期复核**：DevKitC 硬件版本、EDA 客户端版本、固件依赖登记查看日期，纳入 G1 待核实清单复核节奏。

### 4.2 不应照搬

1. **屏幕为核心的电子架构**（MIPI-DSI/FPC/触摸/音频链路）——R1 无屏，不引入任何相关复杂度。
2. **摇杆**——不在 R1 规格（2×2 四键），不因参考工程有而加。
