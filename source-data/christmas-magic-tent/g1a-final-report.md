## 2. A：孩子能否真正躺进去

### 已确认的几何事实

- 详情图明确写「特大款苹果小熊」：**长度165cm、进深105cm、高度135cm**。
- 这是帐篷外廓尺寸，不是底布净长、内墙净长，也没有证明135cm一定等于屋脊净高。
- 图片呈双坡/人字屋顶；入口在165cm宽面一端；前墙至少能看到两个窗，侧/入口方向还有窗或开口。
- 入口内侧可见一整幅网纱帘；外侧布门帘可向两侧系起。
- 页面没有公开檐口高、门净宽、门净高、底布净长、立柱侵占量或地面横杆布局。

### 对100–115cm儿童的判断

G0/G1b模型把“内部净长至少身高+15–20cm”作为舒适目标。若内部净长能保留约130–135cm，丘丘可伸直躺下并放小枕头、薄垫和玩偶；若布底净长明显低于130cm，则115cm身高时余量会变小。外廓165cm加上实际买家反馈，使“可躺着玩”成为合理预期，但不是实测保证。

公开评价中，已明确点选目标165cm实木 SKU 的有效文字样本至少5条，其中：

1. 1条写“两个孩子……在里面玩耍和睡觉”，并称“空间大”；
2. 1条写“我165的身高躺里面都没问题”；
3. 1条写“三个人在里面也不会拥挤”；
4. 2条主要评价好看、孩子喜欢、安装不费事/面料质感。

这些是**买家主观描述**，不是卷尺测量，且没有提供门洞或地面净尺寸。买家实拍图显示儿童可在窗边活动、帐内有完整地面区域；一张细节图可见网纱织物。结论为：

- 4岁半儿童躺着阅读/玩玩偶：**高概率可行，CONDITIONAL**；
- 伸直身体：**合理预期可行，但必须以到货净长验收**；
- 小枕头+薄垫+玩偶：**合理预期可行**，建议薄垫控制在约150×90cm以内，避免挤压侧墙；
- 成人短时间陪玩：买家有165cm成人躺卧和“三人不拥挤”的主观反馈，**可作为体验证据，不作为承重或安全证明**；
- 站立玩耍：不建议。模型显示这是跪坐/躺卧小屋，不是站立空间。

## 3. 骨架与安全

### 实木款已有证据

- 商品参数：框架材质写“实木/pvc”，安装方式“框架式”，适用年龄3–12岁。
- 详情宣传写“实木支架”“天然松木”“安全牢固”；可见木杆实物图。
- 没有公开杆径、杆截面、是否空心、连接头材质、顶梁/横梁数量、螺接/插接方式、安装说明或承重测试。
- 商品图中布套覆盖骨架，无法从公开图确认地面是否有横杆、接头是否突出、孩子碰撞时是否会错位或倾倒。
- 没有找到可靠的杆断裂、接头脱落、晃动或长期拆装负面评价；但评价样本只有10条，不能推导“没有问题”。

### PVC对比

| 项目 | 实木 | PVC |
|---|---|---|
| 当前点选价格 | ¥210 | ¥185 |
| 已知优势 | 可能更少弹性、更有家居质感；买家评价中有“质感/牢固”主观描述 | 轻、通常更易搬运；无木刺风险这一点是材料层面的合理推断 |
| 未知/风险 | 木杆表面可能有毛刺、裂纹，接头结构和实际刚度未知 | 具体管径、接头和抗晃动能力也未知，不能默认同布套、同连接件 |
| 反复拆装 | 可能更稳但更重；需检查端部和接头 | 可能更易拆装但可能更柔；需检查弯曲和接头松脱 |
| 本项目建议 | **优先，但以毛刺/裂纹/接头验收为门槛** | 若实木出现毛刺、裂纹或运输损伤，改选PVC |

结论不是“实木一定更安全”。只是本项目主要是固定室内阅读小屋，且差价只有¥25，故优先实木；若家庭更重视轻量、频繁收纳或担心木刺，PVC是合理替代。

## 4. 通风、进出、材料

- 入口：详情图和买家图都支持双布门帘可向两侧系住；入口内侧能看到完整网纱层。门帘系开后通风较明确。
- 自主逃生：门帘结构看起来可从内侧推开/拨开，但没有厂商关于“儿童可自行开启”的说明；到货应由成人从内部实际测试，不得把系带缠在儿童颈部可触位置。
- 窗户：正面至少两个窗；买家实拍显示窗帘可卷起/系住，窗洞可见。没有证明每个窗都有独立网纱，也没有窗洞净面积数据。
- 关闭门帘和窗帘后：有效通风面积未知；不应在完全封闭状态长时间停留，必须有人看护。
- 面料：页面宣传“A类母婴标准、亲肤透气、可机洗”“高克重、耐磨、无异味”；买家评价称帆布/质感、面料厚实、没什么味道。它们分别是商家宣传和少量买家体验，不等同于当前SKU的完整第三方检测。
- 检测图：详情图展示报告 `HAPTX2412025875`，样品号`2427419`，可见A类宣传、甲醛ND（限值<20mg/kg）、pH6.7、可分解致癌芳香胺染料ND、色牢度项目符合、无异味。图片未证明样品号对应当前165cm实木无垫SKU，故只能记为“检测宣传证据”。
- 禁止事项：商品页没有发现清楚的“禁止悬挂灯串/禁止电子设备/禁止睡眠”条款；不能把未写出理解为允许。项目应按室内短时游戏、阅读、休息使用，不作为无人看护过夜床铺。

## 5. 套餐完整性

目标无垫 SKU 页面只明确写了“实木杆、apple小熊、双门帘、无垫”。页面没有逐项列出：底布、所有木杆、顶梁、连接头、固定件、安装说明、收纳袋。商品图中出现垫子、灯、彩旗、抱枕和布置，但这些属于其他套餐或展示图；不能从图片推断目标无垫 SKU包含它们。

因此购买时应只把以下视为**已明确**：布制帐篷、框架式、实木杆、双门帘、165cm特大苹果小熊款；其他配件在到货验收前全部视为待核。页面另有含灯旗夹、凉席、印花厚垫的独立 SKU，不要混买或把它们当成无垫款内容。

## 6. 家庭落地与DIY

- 最少占地：外廓至少165×105cm；前方门帘完全打开还要留出儿童进出通道。建议预留约 **200×150cm** 的无家具区域；若要成人陪玩，前方再多留约60cm。实际房间尺寸尚未提供，不能把G0模型中的1000×1000cm假设当成已验证条件。
- 软垫：先量到货底布净长和立柱内侧，再裁/买薄垫；不建议先买硬挺、厚重、会顶墙的床垫。可选1.5×0.9m左右的薄折叠垫，价格预算¥40–60，尺寸和商品尚未独立核实。
- 布艺装饰：使用可移除魔术贴、布贴或夹子；不打孔、不缝入承重结构、不绕杆打死结。先在不显眼位置测试粘附和掉胶。
- Arduino星星灯：旧Arduino型号尚未确认，必须先确认5V供电、逻辑电平、可用GPIO和电源能力；若是3.3V板，不直接假设可驱动5V灯带。V1建议按钮+低压LED/WS2812+独立外壳，盒子放帐外或儿童够不到的位置。
- 不把灯串悬挂在帐篷杆或屋顶上；若厂家没有明确允许，采用帐外独立支架、门口桌面灯盒或可拆底座。电池盒、USB线、接头和硬质3D打印件均放在儿童不可拉扯的位置，线缆沿墙固定并留防拉脱余量。
- PIR和声音模块留到后续，单独预算约¥60–100，不计入本轮必买。

## 9. 最终裁决

# CONDITIONAL BUY

可以购买这一个明确SKU，前提是：

1. 购买页面重新点选并截图保存“165cm-实木杆、apple小熊、双门帘、无垫”，不要选到135cm面包小熊或带垫/灯旗套餐；
2. 结算前核对最终价格、免运费和退货宝条款；
3. 到货先不让孩子进入，按独立验收清单检查杆件、接头、毛刺、布面、门帘和网纱；
4. 用卷尺实测底布净长、净宽、门净宽/高和檐口高，若净长不足130cm、门洞不便自主离开、杆件有尖锐/裂纹/松脱，立即拍照留证并按页面退换政策处理；
5. 在验收通过前不安装灯、不贴装饰、不丢外箱。

不推荐无条件放行，因为最关键的内部净尺寸和骨架连接安全仍只有外廓图、买家图和主观评价支持。
