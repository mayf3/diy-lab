## 尺寸（当前参数，待实测约束项见下）

- 两方案总高均 **850mm + 树顶星**；A 底宽 520mm；B 最大枝展约 440mm。
- 帐篷占位 165×105×**135cm** 为**商家规格值，未实测**；比例渲染图中已标注占位。

## 打印适配（P1S 256mm 床）

- 全部零件最大外形 ≤245mm（A_beam_L1_L/R），**平放打印**，均在我仓范围内。
- 方向：梁/柱沿 Z 立着打会 weak——**一律平放**（截面朝上）；树顶星背面朝下；卡扣平放。
- 支撑：星形内凹角需少量手工支撑；其余零件无悬空（设计原则）。
- 耗材：现有 PETG；方案 A 整树耗料估算见 assembly_check.json 体积 ×1.2（暂估，切片后以实际为准）。

## 文件与再生成

- 建模主脚本：`tree_designs_blender.py`（Blender 5.2 headless：建模/渲染/动画）
- 生成器（纯 Python，无第三方依赖，本目录自包含）：`make_decorations.py`（装饰 STL，--board-t 传背板厚）、`make_a4_tree.py`（A4 拼接模板，CFG 待实测参数）、`make_3mf.py`（STL→3MF 打包）
- 产物：`generated/`（STL、3MF、assembly_check.json、a4/）、`generated/blends/tree_designs.blend`（可编辑工程）
- 重跑：`blender --background --python tree_designs_blender.py -- --stage geometry|render|anim|all`
- 装配动画：`renders_local/anim_frames/`（108 帧）→ ffmpeg 合成 MP4（**不入 git**）
