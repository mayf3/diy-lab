## 第一批可制作件

### 1. 毛毡圣诞树 450×650（挂展示板中央）

- 3 层树冠：深绿（顶层 200×190）→ 中绿（300×210）→ 浅绿（450×220），叠放出层次；
- 3 条白色积雪带（波浪边，宽 156/236/356）；
- 红色装饰圆片 Ø40×3 + Ø25×5（缝或魔术贴）；
- 顶端 PETG 星星（`rounded_star_90.stl`，另印）；
- 树干深绿双层加固（可选）。

文件：`generated/felt_templates.pdf`（**39 页真实比例**，每页含 100mm 校准尺）、
`generated/felt_tiles/*.svg`（29 个可编辑轮廓）、`generated/felt_nesting.png`（排料图，
全部材料呈现）、`generated/felt_assembly_preview.png`（拼接预览）、
`generated/felt_cut_list.json`（含 **page_map**：每图案的页号映射）。

**分页与拼接**（v2 真二维分页，可打印区 190×263mm、重叠 15mm）：
- 树冠顶层 200×190 → 2 页（页 1–2）；中层 300×210 → 2 页（页 3–4）；
  底层 450×220 → 3 页（页 5–7）；积雪带/树干页 8–12；红圆片合箱页 38；
- 雪坡 600 宽 → 每坡 4 页（页 29–36）；远景松 A/B 各 2 页（页 13–28）；窗棂小件合箱页 37；
- 每个拼图页印配对页号（如 `tile row 1/2 col 1/3`）+ 四角对位十字 + 重叠带提示；
- **回拼自检**：所有页片段按窗口偏移拼回完整轮廓，与原图逐像素比对
  （缺失 ≤0.5% / 小件 ≤3% 抗锯齿容差），29 个形状全部 PASS（felt_verify.json）。

## 制作顺序（第一轮）

1. **打印校准页**：`felt_templates.pdf` 第 1 页（100%，禁用适应页面）→ 实测
   100mm 校准尺误差 ≤1mm；超差换打印驱动/缩放设置。
2. **裁毛毡树冠**：第 2–4 页，深绿裁顶层（200×190）、中绿裁中层（300×210）、
   浅绿裁底层（450×220）→ 检查：底层底边实测 450±2mm。
3. **裁积雪带**（白）三条 + 树干（深绿，可选）；红色圆片按页裁。
4. **裁背景件**：远景松×8、雪坡×2、窗棂×4（深绿/中绿/白）。
5. **缝魔术贴**：无背胶可缝款，剪 40mm 段 ×6，缝树背面 + 对应展示板位置。
6. **打印 PETG（由你操作 P1S；本轮仅完成切片与数据记录，未启动打印）**：
   先 `rounded_star_90.stl`（9.4g/约 14min，最快验证）→ 检查底槽 40×3.2 与圆角；
   再 `cottage_forest_90.stl`（67.7g，数小时级）；`cottage_xmas` 待切片问题解决。
7. **组装**：树贴展示板中央（魔术贴），背景松/雪坡贴两侧，窗框贴左上；
   PETG 星插展示板顶缘夹位/配重立于矮凳，小屋×2 排矮凳面。
