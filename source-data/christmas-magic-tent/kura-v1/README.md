# kura-v1：KURA 低床无屋顶版（2026-11-16）

## 唯一有效的当前造型基准

- 床：宜家 KURA 502.665.06，参考外形 209×99×116cm，床垫参考平面 90×200cm。
- **低床模式**：床垫靠近地面，上方没有第二层床垫。
- **无屋顶**：标准开放矩形上横梁；不使用旧版本中的屋脊、斜梁、坡面板或天篷，**不额外建屋顶**。
- 标准床架小零件尺寸、低床床垫高度等是可调整的视觉参数，不是实物测绘或安全评估。
- 最后确认的效果图是一张“无屋顶”的圣诞装饰概念图，图片中出现的灯串/上梁装饰不代表实物已验证可安全悬挂。

## 工程交付

`kura_cottage.py`：Blender 5.x 参数化场景；可运行：

```bash
blender --background --python source-data/christmas-magic-tent/kura-v1/kura_cottage.py -- --deco both
```

重新生成 `generated/kura_cottage.blend` 和三张 `renders_local/` 图（随后复制到 `public/media/christmas-magic-tent/kura-v1/`）。`.blend` 分为 `FRAME_LOW_NO_ROOF`、`MATTRESS_LOW`、`DECO_MINIMAL`、`DECO_FABRIC`、`BACKGROUND` 集合；两种装饰可单独开关。

安全边界：不得改动床体结构、不得遮挡上下床与通风、不在睡眠区使用松垂布幔/绳环/灯线或可脱落硬件；上梁花环在数字图里**仅为未验证的视觉选项**，不应作为安装教程。4岁半儿童使用环境应考虑拉拽、跌落与误吞风险。
