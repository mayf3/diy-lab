## 组件区分（对照实拍与官方结构）

1. **KURA 标准床架**：4 立柱 + 顶平台框架（上沿 116 cm）+ 顶部护栏带 + 下铺洞屋
   侧板（松木）+ 板条底 + 平梯。**承重构件，不改装、不开孔、不加载。**
2. **床垫睡眠区**：床垫 90×200 置于顶平台，**床垫顶面 = 睡眠区上界**。睡眠区内
   禁止绳环、垂布、悬挂硬件；护栏内侧不放物。
3. **疑似加装斜屋顶**（非标准件）：双坡面板 + 脊梁。几何全部参数化待实测
   （TM-03/04/05）；在官方安装说明与更多实拍比对确认前，不作为设计依据。

场景文件：`generated/kura_cottage.blend`（可编辑，组件分集合：KURA_FRAME /
MATTRESS / ROOF_SUSPECT / DECO）。重建：`blender --background --python kura_cottage.py -- --deco both`。

## 装饰方案与固定方式（合规性）

**红线（逐条落实）**：不修改床架承重结构；不在床上安装额外挂钩；睡眠区（床垫顶面
及护栏内侧）不加绳环、垂布、悬挂硬件。

| 方式 | 说明 | 合规性 | 待实测 |
| --- | --- | --- | --- |
| A. PETG 免工具板缘夹 | C 形夹，爪距按板材厚度（TM-06：12/15/18 三档备选），单件装饰 ≤50 g，可拆卸 | 非挂钩、无螺丝、可拆卸；位置全部在下铺洞屋外侧板/端板（约 80 cm 高，睡眠区外） | 夹持力与板材厚度 |
| B. 可移除魔术贴 | 不织布背面宽魔术贴贴于侧板平面 | 可拆卸、无残留（需实测） | 贴面残留与承重 |
| C. 配重立放 | 床旁地面大剪影小树 + 底座 | 零固定、零风险 | — |

**禁止**：螺丝/胶粘于承重构件；护栏顶部加载；睡眠区内任何固定件。

装饰物料：现有不织布（绿/白/红）+ 现有 PETG。**不采购新材料。**
