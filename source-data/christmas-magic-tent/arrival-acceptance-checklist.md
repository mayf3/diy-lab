# 到货验收清单｜哎哟宝贝165cm苹果小熊实木无垫

> 先验收，后让孩子进入；先拍照，后丢外箱；不合格不要安装灯和装饰。

## 0. 开箱留证

- [ ] 拍摄外箱四面、快递面单（遮住个人信息）、封口和破损。
- [ ] 录制从开箱到配件平铺的连续视频。
- [ ] 保存商品页面截图：目标SKU、价格、退换政策。
- [ ] 不剪短/不丢弃任何包装、配件袋和说明纸，直到验收完成。

## 1. SKU与数量

- [ ] 标签/订单（若由人下单）与“特大款165cm-实木杆、apple小熊、双门帘、无垫”一致。
- [ ] 没有误发“加大款面包小熊135cm”。
- [ ] 帐篷布罩、底布、全部实木杆、顶梁/横杆、连接头、固定件齐全。
- [ ] 双门帘、入口网纱帘、窗帘齐全。
- [ ] 安装说明或安装视频入口存在；收纳袋若页面承诺则核对，页面未承诺则记录“未见”。
- [ ] 无垫款不应默认有凉席、厚垫、灯、彩旗、夹子；收到多余赠品也不把它当作结构件。

## 2. 木杆与结构

- [ ] 每根木杆在强光下检查毛刺、尖刺、裂纹、压伤、明显弯曲和端部崩裂。
- [ ] 手套/软布沿杆全长轻擦，不应挂纤维或扎手；之后再裸手轻触确认。
- [ ] 连接头无裂缝、缺件、松脱；插接/螺接后不应轻轻一拉就脱落。
- [ ] 按说明完整安装，检查四角是否落地、屋脊是否偏斜、布套是否异常绷紧。
- [ ] 成人轻推两侧墙面，记录是否明显侧向错位、脚部滑移或整体倾倒；此项不是承重测试，不允许压坐/攀爬。
- [ ] 检查帐内地面：无横杆、硬接头、尖端或会硌背的突出物。
- [ ] 发现裂杆、尖锐毛刺、无法锁定的接头、明显晃动或布套无法正确安装：停止使用并留证退换。

## 3. 尺寸实测

用卷尺记录照片和数值，填写到项目日志：

- [ ] 外廓长约165cm、进深约105cm、高约135cm；明确记录测量口径。
- [ ] 底布内侧净长：目标至少约130–135cm，尤其按115cm儿童复核余量。
- [ ] 底布内侧净宽：记录立柱/包边后的最窄处。
- [ ] 门净宽×净高：从实际可通过开口测，不量布帘外缘。
- [ ] 檐口高和屋脊最高点：分别记录，不把总高当檐高。
- [ ] 计算放入薄垫、枕头和玩偶后是否仍能伸直躺下。

## 4. 门、窗与通风

- [ ] 儿童从帐内不借助成人可推开/拨开入口，不被系带卡住。
- [ ] 双门帘可稳定系到两侧，系带不会形成颈部缠绕环。
- [ ] 入口网纱能完整打开/关闭，拉链或边缘无夹手、脱线。
- [ ] 逐个打开窗帘，确认窗洞确实贯通，不是印花/装饰假窗。
- [ ] 记录窗户是否有网纱；若无，关闭门帘和窗帘时不要长时间停留。
- [ ] 室内使用保持至少入口或一处窗开启；必须有人看护，不作无人看护过夜空间。

## 5. 面料和清洁

- [ ] 检查布面、印花、缝线、包边、魔术贴和门帘连接处是否破损/脱线。
- [ ] 闻味道并通风；明显刺激性气味不让孩子进入。
- [ ] “A类、可机洗、无异味”只按页面宣传记录，不自行改写成安全认证；按洗标执行。
- [ ] 记录检测宣传图与实物标签是否有样品/批次对应信息；没有就保持未知。

## 6. DIY前安全门禁

- [ ] 未完成结构、门洞、通风和毛刺验收前，不贴魔术贴、不装电子件。
- [ ] 灯具不挂在帐篷杆或屋顶；先采用帐外独立支架/桌面灯盒。
- [ ] 电池盒、Arduino、USB接头、线束和3D打印硬件置于儿童拉不到的位置。
- [ ] 线缆沿墙固定，有防拉脱和应力释放；不横跨入口和躺卧区。
- [ ] 旧Arduino型号、供电电压和GPIO确认后，才接按钮星星灯。

## 7. 退换触发条件

- [ ] 误发135cm或PVC/带垫错误SKU。
- [ ] 缺少木杆、连接头、底布、门帘或无法按说明安装。
- [ ] 木杆有尖刺、裂纹、严重弯曲，连接头无法锁定，结构明显晃动/倾倒。
- [ ] 帐内净长明显不足130cm，或门洞无法让儿童自主离开。
- [ ] 入口网纱/门帘与页面描述明显不符，或有危险脱线/夹手点。
- [ ] 明显刺激性气味、严重污损、破洞、印花大面积脱落。

退换时保留开箱视频、卷尺照片、缺件清单和页面SKU截图；不要先自行打磨、剪布、打孔或装饰后再主张原始缺陷。
