## 软件扩展为什么简单

WLED 自身有预设、特效、分区、播放列表与 HTTP/JSON API。WLED 灯效可在没有 Mac 常驻的情况下独立运行；Mac 端的 Python 控制程序可通过 LAN 发预设和场景事件。Button Deck 的 K1/K2/K3/K4 将来可映射为暖光/闪烁/彩虹/关灯。WLED 控制器内置麦克风的版本还可以在固件支持时做声音灯效，不需新加 DFPlayer 或 I2S 麦克风。来源：[WLED 官方 JSON API](https://kno.wled.ge/interfaces/json-api/)。

## 供电和儿童安全边界

20 颗 WS2812B 在满白最高亮度时可按 **20×60mA≈1.2A** 粗估，控制器另计电流。初版应限制软件亮度并在 WLED 里设置 **700mA 电流限制**，这不是硬件过流保护或供电认证。只在充分确认 5V 线序、电源负载与儿童不可触及的情况下测试；不从 UNO 的 5V 针脚拖出整条灯串的供电。**WLED 成品控制器要使用厂家提供的匹配接口，不得自行裸线并接。**

树体、灯串和控制器与帐篷完全物理分离，不挂承重杆、不穿门帘、不形成可抓拉线环，不作无人看护睡眠灯。
