# 马丘比丘之家｜2026 万圣节门框装扮

> **实物已完成，细节档案仍待回填。** 2026-10-31 确认门框装饰完成；本文不捏造成品照片、尺寸或订单金额。

## 概念和实际尝试

以「马丘比丘之家」为门牌主题，把 A4 彩色打印与 3D 打印装饰组合成可拆除的万圣节门饰。设计包括血色字母和滴血牌、血迹薄片、南瓜/月亮等主题元素，以及可在节日后移除的粘贴方式。

## 硬件与材料经验

- **2D 打印：** A4 海报分版、裁剪、试贴；正式打印前先在纸上检查尺寸与裁切余量。
- **3D 打印：** Bambu P1S 打印小装饰件；先在 Bambu Studio 验证贴片薄件厚度和首层附着，不凭效果图判断可打印性。
- **固定材料：** 曾讨论/采用可移除胶的方案，包括 Command 胶条、蓝丁胶等。具体选择取决于墙体表面；不能承诺所有漆面绝不脱漆。
- **结构安全：** 装饰避开门铰链、门锁和儿童活动区，开关门应无干涉。

## 给零基础的新手流程

1. 实测门框宽高、门板开启方向，先画一张立面布局图。
2. 在 A4 纸上打印小样贴到门上，检查字体大小、远观效果与通道宽度。
3. 再打印 1–2 个 3D 试件，测量厚度、边缘安全和粘附效果。
4. 先安装背景海报，再安装轻量 3D 配件，最后试开关门。
5. 拆除时先在隐蔽处按胶条说明测试，再清理并记录墙面状况。
6. 补充最终布局、照片、实际成本和使用过的打印文件。
