# Project Christmas Buddy｜圣诞精灵 AI 机器人

> **工程预研完成（2026-11-28）。** 两套电子架构比较、电源预算、网表级原理图、机械模型与装配检查、视觉两方案、Lean 首批证明、工程任务书均已交付并全绿；**未下单、未采购、未打样、未通电**。架构 A/B 决策与盲评等待用户确认。

Christmas Buddy 是一款独立摆在儿童床边的圣诞精灵 AI 机器人：两只 3×3 RGB LED 矩阵眼做表情（不用彩屏），2×2 实体按键（说话 / 重复 / 魔法灯效 / 晚安最高优先），云端 GPT 对话 + 语音识别 + 语音合成，总高 120–160mm，嘉立创 PCB 打样 + SMT 贴片，P1S 打印外壳。

本项目同时是 DIY Lab **第一套 AI 硬件研发样板**：机械与电子共享同一参数源，电气检查、装配干涉、数学模型、Lean 证明、工程任务书全部机器可查，每个结论标注证据等级（官方资料 / 计划或推测 / 实测观察）。

## 研发过程（可复用的样板）

1. **审计**：三仓库现状 + PR 谱系 + 工具链实测，避免重复建设。
2. **预算先行**：每个电流参数带来源三分法，走线宽度按 IPC-2221B 计算。
3. **接口单一源**：原理图、机械、检查脚本共用一份接口定义。
4. **架构比较**：不预设某颗芯片必须存在，加权评分 + 降级触发条件。
5. **网表级原理图**：先机器可查，再进 EDA 客户端画图。
6. **机械-电子联合设计**：PCB 放进外壳用布尔求交验证，不靠目测渲染图。
7. **模型与证明**：安全性质（晚安最高优先、音频互斥、版本四元组门禁）Lean 验证。
8. **任务书驱动**：14 个任务全要素结构化，制造门禁强制人批准。

## 与圣诞魔法帐篷的关系

帐篷项目的 A12/A13 决策（真实卧室约束 + 床外电子暂缓，见 PR #24）明确了：电子互动不应绑在床架/蚊帐场景上。Christmas Buddy 正是把"圣诞 AI 互动"独立成 Free 底座产品的落地——不进睡眠区、不受床架约束、晚安全静音有硬件级保障。
