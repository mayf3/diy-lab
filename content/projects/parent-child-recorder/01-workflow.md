# 亲子教学随身记录器｜设计准备

> **规划中 · 本页记录后续设计任务。** 已确认小型可佩戴硬件、鱼眼相机、亲子教学记录三个方向，挂脖为候选佩戴方式。

## 目标

把已有想法整理成可比较、可验证的设计条件，作为后续选择实现方案的依据。

## 准备

- 已登记的[项目需求](/projects/parent-child-recorder/)。
- 对佩戴位置、取景范围、收音、录制时长、续航、存储和预算的待定项。

## 操作

1. Agent 从已登记需求继续整理，保留与“口喷神器”分别制作的约定。
2. 分清已确定的目标和待设计条件；缺少的参数保持待定，不补成已确认规格。
3. 将“尽可能完整记录教学过程”拆成后续可观察的验收项，例如画面是否覆盖约定内容、文件是否完整保存并可回看。具体场景、时长和合格标准在设计时确定。
4. 形成设计条件草案后，只把会改变方案的新增取舍交给发起人判断。

## 验收

- [ ] 设计条件草案能区分已确认需求与待定参数。
- [ ] 相机项目与口喷神器分别登记，没有预设共用硬件、采购或实施顺序。
- [ ] 取景、录制与回看有可执行的验证方法，未执行的项目保持待验证。

## 出问题怎么办

参数缺失时先保留待定，并说明它会影响哪项设计。若候选佩戴位置无法覆盖目标场景，记录缺失内容，再调整佩戴方式或方案；不能把鱼眼镜头等同于已经实现完整记录。

下一步：设计条件具备后，再比较具体实现方案。当前仍处于想法登记阶段。
