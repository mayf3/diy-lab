# 亲子教学随身记录器

> **可行性验证轮 v2 完成 · 2026-11-18。** 本轮在 v0.2 基础上升级了取景模拟（显式模型口径+画幅裁切+自遮挡+姿态敏感性，384 组）、补齐录制链路验证（三态收尾+分段衔接连续性+容量估算），并扩展路线比较（收音/对焦/佩戴/成本）。**未采购、未焊接、未烧录、未实机制作**；对孩子的一切拍摄均为模拟几何或等你执行的方式，未发生。

制作一个小巧的可佩戴鱼眼相机设备，考虑挂在脖子上等方式，尽可能完整地记录家长与孩子的教学互动过程，方便之后回看。

## 1. 取景模拟 v2（`模拟预测`，非实拍）

模型口径显式声明（见脚本文件头）：离轴角 θ=atan2(hypot(Xc,Yc),Zc)、等距投影、半球角域（相机后半球点判 behind_camera）、θ>θ_max 判 outside_circle；**本轮结论不依赖 >180° 覆盖**。画幅 16:9（1920×1080），按两种镜头安装口径分别计算有效视场——**标称视场 ≠ 各方向有效视场**：

| 安装口径 | 标称 180° 镜头的有效视场 | 标称 150° 镜头 |
| --- | --- | --- |
| fit_height（像圆=短边 1080px） | 水平 180°/垂直 180°（画幅左右为无效区） | 水平 150°/垂直 150° |
| fit_diagonal（像圆=对角 2203px，像圆上下溢出被裁切） | **水平 ≈156.9°/垂直 ≈88.2°** | 水平 ≈130.7°/垂直 ≈73.5° |

**主要结论（均为模拟预测，场景几何/阈值/姿态均为实验假设）**：

1. **有效视场与裁切**：常见"对角填充"安装下，标称 180° 鱼眼的有效垂直视场只有 ≈88°——下倾 20° 后画面上缘在地平线下方；前倾 30°（贴身固定，总下倾 50°）会让对面孩子面部落到画幅外（θ=48.9° 但超出上缘）。**挂绳悬垂对前倾更稳**（朝向只受摆动 ±10° 影响），代价是晃动/翻转风险。
2. **并排读书（S1）是机位硬伤**：孩子面部偏离光轴 85.5°，180°/对角填充下被画幅裁切、150° 下超出像圆；**转身约 45° 才能拍到孩子面部**（θ=43.9°），但转身后抬起的手臂会遮挡（arm_risk/occluded，随姿态变化）。
3. **单一挂脖机位拍不到家长自己的脸**：家长面部 θ≈115–152°，全部判相机后半球（behind_camera）。若"同时拍到双方完整面部"是硬需求，需要第二机位（桌面/三脚架）或胸前翻转配置——**这是待你确认的需求取舍**。
4. **像素宽度**：面对面场景孩子面部 60px（恰好达到 60px 阈值临界）；同一几何下 fit_height 口径的像素宽度只有 fit_diagonal 的一半（书本 109px vs 224px）——**像圆安装口径直接决定有效分辨率**，选型与 DIY 模组固定时必须明确。
5. **遮挡**：躯干/头部在基线姿态不遮挡前向目标；**抬起的手臂**会遮挡手部目标附近的视野并可能扫过孩子面部方向（arm_risk）；衣物遮挡未建模→试录检查项。

自检验证例（正前方点居中、后方点拒绝、超 150° 域、超半球域、画幅内被手臂遮挡、退化距离）全部 PASS。
复现入口：`source-data/parent-child-recorder/framing_sim.py`（`--selftest` 可单独验证；384 组结果见 `generated/framing_sim/results.json`）。

**几何覆盖 ≠ 光学画质**：近距离对焦（GO 3S 官方页未标最小对焦距离）、室内噪点、运动模糊、边缘清晰度不在模型内——列入选型核实项与试录检查项。

## 2. 录制链路验证（`替代实测`：桌面软件链路，合成输入）

链路：ffmpeg 合成 1080p30 输入 → VideoToolbox 硬件 H.264 → 分段 → 停止/中断 → 逐段解码回放。**桌面链路通过不代表目标设备实时性能/发热/续航/持续写入可用。**

| 测试 | 结果（2026-11-18 实测） |
| --- | --- |
| 30 分钟实时录制 + SIGINT 停止（v0.2 已做） | 30/30 分段完整可回放，覆盖 100.0%，8.14 Mbps ≈ **1.83 GB/30min**，CPU 6.6% |
| 45s `-re` 实时输入 × 15s 分段·自然结束 | 3/3 分段完整（15.0s），零解码错误 |
| 同上·SIGINT @40s（分段中段） | 已完成 2 段无损；**写入中分段保住 10.5s 且可解码** |
| 同上·SIGKILL @40s（只操作本脚本 PID） | 已完成 2 段无损；**写入中分段丢失**（MP4 moov 缺失） |
| 150s 崩溃对比（v0.2 已做） | MP4 崩溃中分段整段丢；MPEG-TS 保住约 30s |
| 分段衔接（40s 不限速生成，10s×4 段） | 每段独立解码、每段 300 帧对账一致、各段音视频漂移 ≤0.031s（<1 帧）、concat 后 1200 帧**零解码错误**、总时长 40.047s |
| 30 分钟容量 | **估算**：4Mbps 档实测 1.4 Mbps（低运动内容远低于目标码率）≈ 0.32 GB/30min；**主依据为既有真实运行 8.14 Mbps ≈ 1.83 GB/30min**；按 ±50% 起步、存储按估算值 1.5–2 倍预留 |

时间戳说明：`reset_timestamps=1` 每段归零属正常，连续性由分段清单顺序+各段时长+concat 总时长判断，未误判为丢失。
崩溃边界：`软件崩溃 ≠ 设备断电/拔电池/存储介质故障`——目标设备断电、写满、散热降频全部列为**目标实测待验证**。
复现入口：`segment_continuity_test.py`（本轮）与 `recording_chain_test.py`（v0.2），结果 JSON 在 `generated/`。

## 3. 实现路线比较（`资料核实`，查看日期 2026-11-18）

| 路线 | 内容 | 已核实参数（官方来源见 workflow references） | 收音与佩戴分析（推测项标明） | 主要代价 |
| --- | --- | --- | --- | --- |
| **甲** 成品微型相机+官方挂脖配件 | 如 GO 3S + 磁吸挂绳/脖挂防丢绳 | 39.1g；1080p30 实录单机 **38 分钟**/加 Pod 140 分钟；内置 64/128GB 无 microSD；FOV 度数与最小对焦距离页面未标注 | 自带麦克风规格/AGC 行为未核实（待核实）；挂绳随前倾的晃动风险低于贴身固定但存在翻转可能（试录项） | 单机续航贴 30 分钟基线无余量；价格待预算确认后核实 |
| **乙** 已有手机+挂脖支架 | 零电子件新增，试录专用 | 通用支架 ≈¥15–40（未核实） | 手机多麦克风+AGC 成熟；机身重（150–250g）摩擦声与晃动更明显（试录项） | 仅试录取证用，不长期佩戴 |
| **丙** 鱼眼模组+低功耗主控+外壳 | 180° 鱼眼模组 + RV1106 类 + 电池外壳 | [Core1106](https://www.luckfox.com/Core1106) $26.99 硬件 H.264 1080p30；[Pi Cam 3 Wide](https://www.raspberrypi.com/products/camera-module-3/) 仅 120° 非 180°——180° 需另配鱼眼模组（型号未核实） | 需自配 MEMS 麦克风；AGC/降噪需固件实现（工程量，未开始）；外壳/重量/佩戴未设计 | 工程量最大（固件/电源/外壳/散热），属下一阶段 |

**收音距离估算（`资料核实`原理+`模拟预测`数值，设备规格待核实）**：按反距离律，家长 15cm 参考距离下，孩子 50–80cm 的语音电平低 **10.5–14.5 dB**——回放可辨但偏弱；两人交替/重叠说话时的表现取决于 AGC 策略（**待核实能力，功能名≠已解决**）。近讲削波：大声说话按典型 MEMS 麦克风声学过载点（≥120 dB SPL）推算不易削波，**具体设备待核实**；衣物摩擦声可达接近语音的电平，是挂脖形态的主要收音风险（试录检查项）。

**推荐（v1，条件式）**：先**乙**（约 5 分钟/场景试录，成年人代录、孩子不参加、素材只留本地）核对取景/晃动/收音 → 试录通过且预算确认后选**甲**作为 v1 设备；**丙**列为下一阶段工程路线，不阻塞乙/甲。
**变更条件**：试录显示挂脖/胸前取不到有效画面 → 加第二桌面机位（同时回答"双方面部"需求）；需要 30 分钟以上连续且不接受 Pod → 甲让位丙；GO 3S 最小对焦距离试录不过（书本虚焦）→ 筛选可近焦的同级设备或转向丙。

## 4. 需要你决定 / 动手的事（本轮最小集）

1. **分钟级试录（A05）**：用你的手机按三个场景各试录约 5 分钟（**成年人代录，孩子本轮不参加**），按清单核对：取景覆盖 / 前倾转身时挂绳晃动与镜头朝向 / 收音（对话清晰度、近讲是否破音、衣物摩擦声）。素材留本地。
2. **需求取舍确认（A01 尾项）**：①"全场景覆盖 vs 看清表情"（像素临界）；②"是否必须同时拍到双方完整面部"（单一挂脖机位拍不到你自己的脸——第二机位 or 接受仅孩子方向画面）。
3. **路线与预算（A06 解锁条件）**：确认前不产生任何采购；BOM 只含推荐路线（乙试录支架 + 甲设备候选），保持 HOLD。

## 验证边界（哪些结论不能外推）

- `模拟预测` 的场景几何、阈值、遮挡体尺寸、姿态幅度全是实验假设：真实客厅、孩子实际位置、佩戴真实高度与摆幅待试录修正。
- `替代实测`（桌面 FFmpeg）不代表目标设备的实时性能、发热、续航、断电行为与 SD 卡写入可靠性。
- `资料核实` 的官方续航是厂商测试条件（25°C、Wi-Fi 关、屏关、1080p30），实际使用会打折。
- 公开仓库只保留合成样例、去识别示意图与统计数字；真实家庭音视频只在本地。
