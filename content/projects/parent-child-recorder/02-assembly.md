# 亲子教学随身记录器｜V1 零焊接组装教程

> **教程=执行方法，非执行结果。** 本页按「拆箱→接线→系统安装→设备识别→录制软件→外壳装配」六步组织，全部为插拔件、零焊接。目标：做出第一台**能通电、能识别摄像头和麦克风、能保存录制文件**的自制电子设备。每步给出「应看到什么」与「失败怎么办」；实机执行记录由 A08/A10 回填，本页不冒充实测。

## 目标

用最少步骤把 Zero 2 W + 摄像头 + USB 声卡 + SD 卡拼成可录制的台架设备：通电开机 → 系统识别摄像头与麦克风 → 保存一段视频和一段音频文件到 SD 卡。外壳装配为最后一步（依赖 A09 设计与实物尺寸）。

## 准备

- 购物清单见 [BOM](/downloads/parent-child-recorder-bom.csv)：主控 Zero 2 W、摄像头（主选微雪 RPi Camera (G)，OV5647 160°，**装箱含 15pin FFC + Zero 专用排线，无需另购**）、64GB SD、USB 声卡+领夹麦、micro-USB OTG 适配器、M2 螺丝包。
- 复用材料：micro-USB 供电线、充电宝（5V≥2A，建议 3A 余量）、PETG/P1S。
- 一台能写 SD 卡的电脑（用户现有 Mac）+ 读卡器。
- 全程无电烙铁；所有连接均为插拔件。

## 操作

### 第 1 步：拆箱与核对（10 分钟）

1. 核对 BOM 逐件到货：主控、摄像头（**确认盒内两条排线：15pin FFC + RPi Zero V1.3 Camera Cable**）、SD 卡、声卡、领夹麦、OTG 适配器。
2. 检查主控板上 micro-USB 双口：**靠近板边的「PWR」口只供电，另一个「USB」口是数据 OTG 口**——认错口是新手最常见错误。
3. 静电防护：触摸金属物放电后再拿 PCB；只捏板边。

**应看到**：所有物品与 BOM 对上，主控双 USB 口丝印清晰。
**失败怎么办**：排线缺失→联系卖家补发或按 BOM 加购（22pin→15pin）；板子外观破损→直接换货。

### 第 2 步：接线（15 分钟，全部断电操作）

1. **CSI 排线**：先轻拔主控 CSI 座的黑色卡扣，将 **RPi Zero V1.3 Camera Cable** 的金属触点面**朝下**（背向网口方向）插入主控 22pin 座并压回卡扣；另一端 15pin 插入摄像头座（该端卡扣方向按座子实际方向，触点对触点）。微雪 Wiki 对 Zero 系列的原话：「将排线的金属面朝下，接入摄像头接口」。
2. **不要通电**的情况下插 SD 卡（金属面朝主控板背面/按座子丝印）。
3. USB 声卡插 **OTG 适配器 → 主控数据 USB 口**（不是 PWR 口）。
4. 领夹麦插声卡 3.5mm 口。
5. 最后接供电：micro-USB 线插 **PWR 口**，另一端接 5V≥2A 电源或充电宝。

**应看到**：通电后主控板上绿色 LED 开始闪烁（系统已在 SD 卡内时）。
**失败怎么办**：绿灯不亮→换电源线/电源（劣质线限流）；红灯亮但绿灯不闪→SD 无系统，进第 3 步。

### 第 3 步：系统安装（30 分钟，Mac 上操作）

1. 下载并安装 [Raspberry Pi Imager](https://www.raspberrypi.com/software/)。
2. 选择设备「Raspberry Pi Zero 2 W」→ 系统「Raspberry Pi OS (other) → **Lite**（64 位可跑，32 位兼容）」→ 存储=SD 卡。
3. 点下一步前的设置齿轮（OS customization）：设置主机名 `recorder`、开启 **SSH**（密码认证）、配置 WiFi（家里 2.4GHz SSID/密码——Zero 2 W 只支持 2.4GHz）、设置用户名密码。
4. 写入完成后 SD 插回主控，通电等待 2–3 分钟首次启动。
5. Mac 上 `ssh 用户名@recorder.local`（或用路由器后台查 IP）。

**应看到**：SSH 登录成功，出现命令行提示符。
**失败怎么办**：`recorder.local` 解析失败→改用路由器后台查 IP 后 `ssh 用户名@IP`；WiFi 连不上→确认 2.4GHz、密码无特殊字符，或接显示器+键盘现场看报错。

### 第 4 步：设备识别（15 分钟）

```bash
sudo apt update && sudo apt install -y rpicam-apps  # 一般已预装，缺则补
rpicam-hello --list-cameras                          # 摄像头识别
lsusb                                                # USB 声卡识别
arecord -l                                           # 麦克风/录音设备列表
```

**应看到**：`--list-cameras` 列出 `ov5647 [2592x1944]`；`lsusb` 出现声卡厂商条目；`arecord -l` 列出录音子设备。
**失败怎么办**：
- 摄像头未列出→断电重插排线两端并确认金属面方向（最常见是排线方向与深度）；仍不行换排线。
- `arecord -l` 无设备→`lsusb` 看声卡是否在列；在列但无录音设备→换声卡或确认麦克风插入口（Mic in 不是 Line in 的卡需转接）。

### 第 5 步：录制软件与首段文件（20 分钟）

```bash
# 视频：硬件 H.264 编码（rpicam-vid 走 VideoCore 硬件编码器）
rpicam-vid -t 10000 --width 1920 --height 1080 --framerate 30 \
  --codec h264 -o /home/$USER/test_video.h264
# 音频：alsa 录 10 秒
arecord -f S16_LE -r 44100 -d 10 /home/$USER/test_audio.wav
# 播放检查（接耳机或拉回 Mac 播放）
aplay /home/$USER/test_audio.wav
# 拉回 Mac 合成预览（Mac 上执行）
scp recorder用户名@recorder.local:/home/$USER/test_*.h264 . 2>/dev/null || \
  scp 用户名@recorder.local:/home/$USER/test_video.h264 .
ffmpeg -r 30 -i test_video.h264 -i test_audio.wav -c copy preview.mp4
```

**应看到**：`test_video.h264`（10 秒 1080p30 硬件编码）与 `test_audio.wav` 生成、大小合理；ffmpeg 合成的 preview.mp4 可播放。
**失败怎么办**：`rpicam-vid` 报错 no camera→回第 4 步；编码帧率远低于 30fps→记录实际数值并反馈（这正是 A08 要收集的数据，必要时先降 720p30）；文件 0 字节→SD 卡写入问题，换卡槽方向或换卡。

### 第 6 步：外壳装配（A09 完成后）

1. 按 A09 的外壳说明装入主控与摄像头：镜头对准窗口（**手动对焦环按书本距离预调**），M2 螺丝固定四角（不拧死，留调焦余量）。
2. 声卡+领夹麦走线孔引出；充电宝不进壳、放口袋由线连接。
3. 佩戴试戴（成年人）：检查视线遮挡、重量分布、线缆应力；不舒适处反馈给 A09 迭代。
4. 安全边界：不在床垫上方/睡眠区安装悬挂件；试戴者是自己（成年人），孩子不参加第一轮。

**应看到**：穿戴后第 5 步的录制流程仍稳定工作。
**失败怎么办**：外壳干涉排线/镜头→拍照记录尺寸偏差反馈给 A09 重设计；佩戴不稳→先夹口袋方案过渡，不硬调。

## 验收

- [ ] 到货核对：BOM 逐件对上，摄像头盒内含两条排线。
- [ ] 接线：CSI 金属面朝下插入主控；声卡走数据口、供电走 PWR 口。
- [ ] 系统：SSH 登录成功。
- [ ] 识别：`rpicam-hello --list-cameras` 列出 ov5647；`arecord -l` 列出录音设备。
- [ ] 录制：10 秒 1080p30 `test_video.h264` + 10 秒 `test_audio.wav` 保存成功并可回放。
- [ ] 外壳：装配后录制流程仍稳定（依赖 A09 完成）。
- [ ] 实测数据回填 A08（帧率/温度/写入）。

## 出问题怎么办

- 任何一步卡住：先拍照记录「命令+完整报错+接线照片」发给 Agent，不要盲目重插拔超过 3 次。
- 摄像头识别失败按概率排序：排线方向 → 排线插深 → 排线本身 → 摄像头座损坏。
- 供电不足症状：红灯亮/绿灯不闪、键盘僵死、WiFi 掉线——换粗短供电线或更高输出电源。
- 本页命令若因系统版本差异报错：把 `rpicam-vid --version` 与报错全文反馈，不要自行改内核配置。
