# G3–G4｜16 键、旋钮、无线、语音与实物验收

## 目标

把四键基线做成可扩展模块，而不是从一开始买齐 PCB、屏幕、电池和麦克风。**G3 每种扩展分别立项，G4 真实测试后才提升项目状态。**

## 准备

G0–G2 的测试记录、板卡真实型号和 [BOM](https://github.com/mayf3/diy-lab/blob/main/source-data/agent-button-deck/bom.csv)。没有打印机可用纸板/面包板测试或代打印，不强制使用 P1S。

## 操作

1. **更多按键**：官方 [Microchip MCP23017](https://www.microchip.com/en-us/product/mcp23017) 是 16 路 I²C IO 扩展器；可以规划在 ESP32-S3 的 `GPIO8 SDA`、`GPIO9 SCL` 上接 3.3V 兼容模块，支持额外 16 个逻辑键（总共最多 20）。但必须先核实实际模块 I²C 上拉、地址、电平与引脚，**现有 4 键固件尚未实现此扩展**。
2. **旋钮**：候选 EC11 编码器（转动、按压分别触发事件）；尚需去抖与引脚实测。支持 `K1..K64` 的 Mac 接收解析器不代表固件已实现 64 个物理键。
3. **无线**：ESP32-S3 可做 BLE，但 BLE HID（发键盘热键再由 Mac 映射）和自定义 BLE GATT（发原始 K 编号、需要电脑 BLE 客户端）是**两个不同实现**。断联、重连、休眠、重复发键和电池安全必须独立测试。没有标准 Mac 红外接收器时，红外需额外 USB 接收设备，不选为首发。
4. **语音**：先让按钮启动 Mac 自带麦克风上的录音/转写快捷指令，用户能够明确停止和看到录音提示；以后可考虑 I²S MEMS 麦克风，届时要解决数据采样/传输/ASR/隐私。**V1 不做永远开麦的监听器**。
5. **外壳**：做可拆的四键 3D 打印模块，留 USB 防拉扯、线缆槽和替换按键的空间。先用纸模型和小尺寸量规验孔位，实测匹配后再打印整壳；不要依赖未验证的克隆板尺寸。

## 验收

- [ ] 四键依次各按 10 次，逐键观察 10 条事件；长按 2 秒不连发。
- [ ] USB 拔插 3 次，都能重新连接，记录成功/失败次数而不筛掉失败样本。
- [ ] 电脑端换一个映射，无需刷板即可更改动作。
- [ ] K4 无授权本地 adapter 时**安全失败**，绝不猜测或自动打开私人目标 API。
- [ ] BLE、扩展 IO、旋钮、语音、外壳只在真实测试并有记录后，才单独勾选“通过”；不能写成首版已具备。

## 出问题怎么办

I²C 扩展板无回应先**断电**核对地址、SDA/SCL、3.3V、电平和上拉，不向 GPIO 输入 5V；BLE 掉线先退回 USB 基线而不是改 Agent 逻辑；录音异常就停止录音并撤回权限；外壳尺寸冲突先打印量规，不反复浪费整盒材料。所有失败留在日志，不冒充实测通过。
