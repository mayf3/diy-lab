# Agent Button Deck｜AI 实体快捷控制台｜新手制作路线（人类版）

> **自动生成·工作流仍是计划，不是实物测试报告。** 本页由 source-data/agent-button-deck/workflow.json 生成；不能把 AI 看过网页、切片预览或用户勾选说成已经制作成功。

你不需要自己逐页检索上游仓库、核对复杂零件规格或独立判断设备兼容性。**把具体调查交给有文件和网络访问权限的 Agent**；你只做目标选择、必要的实物操作、付款和实机验收。如果没有 Agent，仍可以点击每一关的详细教程按传统方式进行。

**目标**：制作以四个实体按键起步的电脑控制器：硬件只发匿名按钮 ID，Mac 侧用户自定安全映射，后续可通过另行授权的 adapter 路由到指定 Agent。
**完成标准**：真实 4 键各发准确事件且长按不连发，Mac 上至少两种经过确认的本地动作可正确完成，每键 10 次和 USB 重插 3 次均保存日志；真实 Agent 会话投递要另有合法 adapter 和回执。

### 第 5 关｜断电接线和首次烧录

**这一关要拿到：** 用 GPIO4–GPIO7 读取四个常开按钮并发送串口 JSON。

**交给 Agent 完成**：

**你亲自做**：

- 断电完成按键和 GND 接线、检查有无短路
- 批准首次插 USB 和烧录，按键提供脱敏串口日志

**完成时应该有：** 接线照片和板卡型号、Arduino Core 版本及四键日志。

**怎样判断：** 四键输出无串台且按住两秒不连发；必须是实机记录。**当前证据状态：planned**（未运行不能算通过）。

**卡住或失败：** 过热/反复复位/触点未明立即拔线，禁止用 G0 当作通电验收

### 第 7 关｜隔离指定 Agent 会话路由

**这一关要拿到：** 区分打开网页和经 adapter 真正投递 Agent 事件。

**交给 Agent 完成**：

能打开会话不等于能发消息；真正投递需你授权的本地 adapter。

**你亲自做**：

- 自行决定是否部署/启用有权限的 Agent adapter
- 仅在明确授权时进行一次端到端目标与回执测试

**完成时应该有：** adapter 契约或真实测试回执。

**怎样判断：** 确实有获授权 adapter 将事件送达正确会话并返回可核对回执，才能称完成。**当前证据状态：planned**（未运行不能算通过）。

**卡住或失败：** 无 adapter/合法 API 时仅打开会话网址或继续 dry-run
