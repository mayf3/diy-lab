# 第 7 步｜焊接、排线与裸机检查

## 目标

把定制 PCB、开发板、摇杆和按键正确连接，**先验证裸机，再安装外壳**。预计 2–4 小时；第一次焊接可能需要更久。

## 安全与准备

- 在通风良好的成人工作台操作，远离孩子与可燃材料，佩戴护目镜。
- 使用控温电烙铁、焊锡、助焊剂、镊子、斜口钳、万用表；烙铁温度根据焊料与元件规格设置。
- 所有插拔、焊接、导通检查都要在 **USB 完全断开** 后进行。
- 不在带电状态下插拔 MIPI 排线、开发板、扬声器。
- **先练习废 PCB**：会焊一个整齐的焊点，并能用万用表识别短路，再碰正式板。

## 装配顺序（请与官方视频核对）

1. 将 PCB 放在干净的防静电工作面，核对 `SW1–SW3` / `U1` / `U2` 丝印及方向。
2. **只插不焊**：将两根 20P 排母、摇杆、三个机械轴分别插入，逐个确认引脚与孔位一一对应、没有需要强行掰脚的地方。
3. 依据官方装配视频先焊矮件或易定位件；每焊一排检查是否有桥连、冷焊、焊盘掀起。
4. 用万用表检查疑似相邻短路点；特别核对排母的每个引脚没有搭到旁边。需要时用吸锡器/吸锡带修正。
5. 对准方向插入已焊排针的 ESP32-P4-WIFI6-M，不能错位插偏一排。
6. **完全断电**后将匹配的 FFC 连接到主控板 **MIPI-DSI** 插座而非 CSI。先观察锁扣结构，轻插后扣紧，不能直接暴力拉扯。
7. 将匹配规格的扬声器插入板载 1.25mm 2P 音频接口，不要接成 3.3V 供电或 GPIO。
8. 在未装壳状态下再次检查 PCB 下方是否有裸露金属短接；将板放在绝缘台面准备通电。

## 第一次上电只检查基础情况

1. 用**可传数据的 USB 线**连接 Mac，不安装上游未提供的非官方驱动。
2. 看开发板电源指示灯是否有合理状态；Mac 是否检测到 USB/串口。
3. 如果没有固件，屏幕不亮或没显示预期动画是正常待查现象，**不应据此判定硬件损坏**。
4. 发现异味、异响、明显过热、供电重复断连就立即断电，排查短路/方向后再试。

## 验收

- [ ] 正式板的所有焊点已用放大照片检查。
- [ ] 主要连接与相邻短路风险已用万用表复核。
- [ ] 断电状态正确安装 DSI 屏和音频线。
- [ ] USB 上电无异常发热或异味。
- [ ] 留下正反面、排线方向和开发板型号的照片。

## 出问题怎么办

焊孔不匹配：**不要剪掉引脚、斜着强焊或破坏 PCB**，回到第 3 步确认 BOM 与版本。若主板插入后无法上电，断开所有外设，再逐步增加模块隔离问题。需要判断线路时优先使用微雪官方原理图和 EDA 网络，不凭颜色猜线。
