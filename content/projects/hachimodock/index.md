# HachimoDock：零基础制作一台 AI 桌面搭子

> **制作状态：准备中，尚未采购和实物验证。** 这是独立复刻学习记录，不是上游官方教程。项目资料截至 **2026-11-06** 核对；设备、材料、屏幕和 PCB 需要你到货后逐步实测。

HachimoDock 不是在小盒子里运行大语言模型：它通过 USB 与电脑上的 HachimiDock 管理端通信，让 Codex 等 Agent 的状态变成小屏动画，并通过按键、摇杆、语音与电脑交互。我们的目标是**原样复刻第一台，完全跑通后再定制**。

## 最终要做成什么

- 获得适配的外壳与屏幕外框：可以自己用**任意适配的 3D 打印机**打印、借用机器或选择**代打印服务**；P1S 只是作者的实测设备之一。
- 将 ESP32-P4-WIFI6-M、2.8 英寸 MIPI-DSI 屏、3 个按键、摇杆、扬声器和 PCB 组合起来。
- 在 Apple silicon Mac 上安装客户端、正确烧录 v1 或 v3 对应固件。
- 展示真实的 Codex 工作状态，并完成按键、摇杆、声音和重新连接测试。
- 整个过程留下材料采购、测试证据、照片、短视频和复盘，供其他新手参考。

## 没有电子制作经验，也可以做吗？

可以把整个项目拆成小关卡来做。**不需要先买 3D 打印机**：有打印机走本地切片/打印路线，没有就走代打印路线。焊接、识别排线方向和烧录是按具体任务需学习或委托有能力的人员完成的步骤。建议第一次焊接先练习废板，不要拿正式 PCB 直接试手。

## 按顺序走的路线图

1. **不花钱**：理解设备，下载官方文件，确认版权和版本。
2. **不花钱**：整理购物表，确认芯片修订版、屏幕排线、机械轴与 PCB 兼容。
3. **不花钱**：在 FreeCAD / Bambu Studio 模拟外壳、主板、屏幕位置。
4. **再付款**：PCB 打样、购买电子元件；试打印配合件。
5. **装配调试**：焊接 → 裸机检查 → 烧录 → 连接 Mac → 完整装壳。
6. **出作品**：功能验收 → 拍照 → 视频 → 实际成本与失败记录。

## 第一台项目的三个购物红灯

- **芯片版本**：ESP32-P4-WIFI6-M 的 `M` 表示带排针版本，**不**表示 ESP32-P4 silicon v3。v1/v3 的完整烧录包不能互刷。
- **屏幕和排线**：仅有“2.8 英寸 480×640”还不够；必须同时核对 MIPI-DSI、FFC Pin 数、方向、长度和驱动/初始化兼容性。
- **机械轴与 PCB**：官方文字建议 BOX 轴，但立创 BOM 中写的是 CPG135001D01（CHOC 系）。PCB_V1.2 网表/封装也曾有复刻者提问；**先核实再下单**。

## 预算与时间

基础电子物料网页参考价合计约 **¥167 起**（不含 PCB、排线、键帽、邮费、耗材和工具）；用于做预算的单台估算 **¥220–360**，不是商家实时报价。预计主动操作 **约 8–15 小时**，物流和试错另算。
