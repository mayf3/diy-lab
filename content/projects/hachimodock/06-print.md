# 第 6 步｜P1S 试打印与正式打印

## 目标

先用现有材料做低成本结构验证，再打印正式机壳。你的设备是 **Bambu P1S、0.4mm 喷嘴**；这一步可以完全沿用已有万圣节 3D 打印经验。

## 先分清文件

立创 3D 模型区的两份原始文件分别是 **外壳** 与 **屏幕 lens / 外框**。首次不要自己改整体缩放，先按上游几何验证。保存 STL/3MF 转换件到私有的 `working/` 文件夹，记录来源，避免因法律不明上传第三方设计文件。

## Bambu Studio 首次试打印建议

| 设置 | 建议起点 | 说明 |
| --- | --- | --- |
| 设备 | P1S / 0.4mm | 核对选择的打印机与喷嘴 |
| 材料 | 现有 PLA，或已有 PETG | 不必先买新颜色 |
| 层高 | 0.20mm | 先追求稳定，不必超细 |
| 壁数 | 3 | 提升壳体强度 |
| 填充 | 15%–20% | 仅作为初始值，按实际零件调整 |
| 支撑 | 通过切片预览判断 | 螺孔和接触面不要轻率铺满支撑 |
| 缩放 | 100% | 除非你明确知道公差原因 |
| Brim | 小接触面时启用 | 防翘边，按模型而定 |

**这不是已实测的最佳 Profile**。STEP 具体朝向、支撑量、总耗材和打印时间只能在你下载、切片后得到，不能先填虚构数据。

## 操作

1. 在 Bambu Studio 中导入 STEP（若不支持，先用 FreeCAD 转换为 STL），核对单位 mm 和比例 100%。
2. 查看模型是否包含多个独立子件，必要时“拆分为对象”。
3. 将较平的基底放在打印板上，依照支撑预览调整朝向；让可见外观面尽可能少受支撑影响。
4. 预览每层，重点看 **悬空、薄壁、螺孔、热熔螺母孔、屏幕卡口**；记录切片截图与估算克重。
5. 如可拆分，先打一枚螺母孔/按键开口试件；若不能拆件，则用低成本整件试打印。
6. 试件冷却后和实物 PCB、屏幕、轴体逐项干配，不要先上胶或热熔螺母。
7. 有尺寸偏差时，记下 **设计尺寸、实测尺寸、材料、打印方向**，再在自己的派生设计中修订。
8. 全部配合通过后，用最终材料与颜色重新切片、正式打印。

## 验收

屏幕能进入开孔，PCB 与主控可进入预定空间，机械轴及摇杆操作不被外壳卡住，USB 数据线可插拔，预留排线不被挤压。**只有外壳打印成功不等于整机装配成功**。

## 出问题怎么办

- 卡口太紧：先排查是否下载了正确版文件、是否无意缩放、是否打印翘曲。
- 热熔螺母孔偏小：在废件上测试温度和压入手法，不能直接压坏正式机壳。
- PETG 拉丝：按材料厂家推荐范围调节，先做小件质量测试。
- 透明屏幕 lens 刮花：单独保护，避免打磨粉末或强力胶接触显示面。
