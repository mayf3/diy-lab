# HachimoDock 哈基米机｜新手制作路线（人类版）

> **自动生成·工作流仍是计划，不是实物测试报告。** 本页由 source-data/hachimodock/workflow.json 生成；不能把 AI 看过网页、切片预览或用户勾选说成已经制作成功。

本页所有进度状态（已完成/未进行）描述的是**作者案例**：作者验证到什么程度、凭什么证据。它们不是你的进度；你的个人勾选只保存在你自己的浏览器里。

你不需要自己逐页检索上游仓库、核对复杂零件规格或独立判断设备兼容性。**把具体调查交给有文件和网络访问权限的 Agent**；你只做目标选择、必要的实物操作、付款和实机验收。如果没有 Agent，仍可以点击每一关的详细教程按传统方式进行。

**目标**：复刻能通过电脑客户端显示真实 Agent 状态的 HachimoDock 桌面装置。
**完成标准**：实物完成结构、输入、显示、音频和 USB 重连测试，能看到一次真实 Agent 状态变化，并记录真实证据。
