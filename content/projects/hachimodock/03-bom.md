## 三个必须过的购物门禁

### A. 开发板 v1 还是 v3？

向卖家确认 **ESP32-P4 芯片修订号**。`ESP32-P4-WIFI6-M` 中的 M 通常表示开发板排针配置，不表示芯片是 v3。确认修订版后才能选择完整烧录包。记录店家回答截图。

### B. 屏幕和 FFC 能不能配？

请店家确认：精确屏幕型号、MIPI-DSI 兼容性、排线两端 Pin 数、间距、触点同向/反向、长度、面板玻璃外形和安装尺寸。曾有官方评论区复刻者购买 15P 屏幕遇到连接不匹配；另一条经验提到 22P、0.5mm、同向 FFC，但**该经验不是通用兼容证明**。

### C. 机械轴/PCB 如何配？

上游正文曾写 BOX 轴，但 **2026-11-06 在原理图 SCH_V1.2 与 PCB_V1.2 BOM 均查到 `CPG135001D01` / `C400229`**，当前以该精确型号作为采购候选。**剩余 HOLD 是键帽/轴高与外壳实际干配**，不应把历史文字差异扩大成“完全不知道买哪种轴”，也不能因此宣称实物配合已通过。由 Agent 检查 EDA 与 STEP；必要时只请人提供无法公开取得的实物尺寸/商家答复。

## 可以发给商家的询问模板

> 我准备按照 HachimoDock 官方 `PCB_V1.2` 复刻，请确认这款商品的**精确型号、引脚/排线定义、机械尺寸**，是否在 ESP32-P4-WIFI6-M + 2.8 寸 480×640 MIPI-DSI 场景真实验证过。请提供照片、规格书或成功装配记录，不要仅根据尺寸相似推荐替代品。

## 付款之前

- [ ] 取得开发板 v1/v3 修订号，记录证据。
- [ ] 取得屏幕型号与完整排线规格，核对 DSI 而非 CSI。
- [ ] 解决 PCB 与机械轴的兼容疑点。
- [ ] 报价包含 PCB 数量、加工、运费、附属器件、打印耗材。
- [ ] 已完成下一关的虚拟装配检查，确定没有明显结构冲突。

## 验收

不是“购物车加满了”，而是**每个不确定部件都有对应证据或明确 HOLD（不付款）状态**。

## 出问题怎么办

卖家不能确认就换能够出示规格书的供货商，或向原作者 GitHub Issues / 立创评论区询问；不要用“看起来一样”来判断。PCB 与轴体疑点未解决时，可以继续模拟外壳，但暂停 PCB 和按键采购。
