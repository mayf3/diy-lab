# 第 1 步｜先读这个：项目与关卡

## 目标

在不买东西、不焊接的情况下，确认要做的设备、可复用工具、风险以及**下一关需要完成什么**。预计 15 分钟。

## 准备

- 一台能访问 GitHub 的 Mac（本教程以 Apple silicon 为例）。
- Bambu P1S / Bambu Studio；你已有，后续复用即可。
- 一个可存放资料的文件夹，例如 `~/DIY/HachimoDock/`。

## 操作

1. 打开 [项目作者 GitHub](https://github.com/YizhengWw/HachimoDock)，查看当前发布的桌面客户端与固件版本。
2. 打开 [立创硬件项目](https://oshwhub.com/eda_gqvzlprk/project_cnbmkbjc)，找到 **PCB / BOM / 3D 模型 / 装配附件**，先确认可以看到下载入口，不需要先下载全部。
3. 在 Mac 上建四个文件夹：`originals`（上游下载文件）、`working`（加工文件）、`evidence`（照片截图）、`notes`（日志）。**不要将上游资料直接再公开到本 GitHub**。
4. 阅读 [版本与来源](/projects/hachimodock/02-sources/) 的许可证提醒。
5. 在下面勾选你已有的工具；缺的先记在笔记，不用立即下单。

## 新手术语

| 词 | 意思 | 本项目的用途 |
| --- | --- | --- |
| STEP | 可编辑/测量的三维模型 | 外壳、屏幕配合检查 |
| STL / 3MF | 3D 打印与切片相关文件 | P1S 打印结构件 |
| PCB | 定制电路板 | 固定摇杆、按键、排母 |
| Gerber | 工厂用于制作 PCB 的生产文件 | 下单前导出/核对 |
| FFC | 扁平软排线 | 连接屏幕，方向和 Pin 数很关键 |
| 固件 | 写入 ESP32-P4 的设备端程序 | 驱动屏幕、按键与通信 |
| SHA-256 | 文件校验摘要 | 检查下载包是否完整 |

## 需要用到的工具

- [ ] Bambu P1S 可以正常开机与切片。
- [ ] 已安装 Bambu Studio（若版本不同，记录当前版本）。
- [ ] 有 USB **数据线**，不是仅充电的线。
- [ ] 能借到或购买电烙铁、焊锡、万用表、小螺丝刀。
- [ ] 有安全、通风、远离儿童的焊接空间。

## 验收

能用自己的话回答：**“我究竟在做什么？”** —— 用 ESP32-P4、屏幕和按键做一个 USB Agent 交互终端，由 Mac 上的客户端提供状态与服务。知道首先要解决的是兼容性，不是外壳颜色。

## 出问题怎么办

如果 GitHub 或立创打不开，先记录 URL 和日期，不从不明群聊网盘下载镜像。若没有焊接工具，可将焊接作为后续关卡；现在仍然能完成第 2–4 步。
