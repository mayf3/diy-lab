# 第 1 步｜先读这个：项目与关卡

## 目标

在不买东西、不焊接的情况下，确认要做的设备、可复用工具、风险以及**下一关需要完成什么**。预计 15 分钟。

## 准备

本页保留早期以 Mac / P1S 为例的深入操作说明，**不是购买要求**。先从 [人类制作版](/projects/hachimodock/human-track/) 或 [Agent 执行版](/projects/hachimodock/agent-track/) 进入；没有打印机可以选择借用/代打印，没有 Mac 则需要 Agent 核实官方当前支持的客户端平台。任何未知机型不要套用 P1S 切片参数。

- 有一台可访问网络的电脑或能协助你操作的 Agent 环境；具体系统支持条件请由 Agent 查询当前官方 Release。
- 可用的 3D 打印方式：自己的任意兼容打印机、借用设备或代打印服务，不必购买 Bambu P1S。
- 用于保存官方原始资料与制作记录的空间；允许 AI 代为组织目录。

## 早期操作的 Agent 替代入口

下面旧流程第 1–2 项“打开 GitHub/立创看文件”已经迁移为 **Agent 工作流 A02/A03**。有工具权限的 Agent 应自行核对并返回结果；仅在需要登录或文件不可访问时，向制作人索取最低限度文件。人不需要自行判断固件版次和 PCB 封装。

- 可以让有工具权限的 Agent 访问官方资料的设备；不必是 Mac。
- 有自有打印机、借用打印机或代打印任一路线即可；暂时没有也没关系。
- 保存资料和日志的文件夹；可让 Agent 帮你组织。

## 操作（有 Agent 时优先用这一种）

1. 打开 [人类制作版](/projects/hachimodock/human-track/)，把其中的 Agent 委托话术复制给你的 AI 助手。
2. 告诉 Agent 你使用的电脑系统、预算、3D 打印资源（没有就说没有）和焊接条件。
3. 让 Agent 在能访问的情况下直接读取官方 GitHub、立创 EDA 与微雪资料，并给你返回“已查证 / 仍未知 / 需要你做什么”。
4. 从 Agent 的资源分流建议中选择自有设备、借用或代打印；**此时不要下单**。
5. 读懂下文的新手术语即可。没有 Agent 的读者才按以下原始手工步骤查找资料。

## 无 Agent 时的手工备选（不是默认工作量）

1. 打开 [项目作者 GitHub](https://github.com/YizhengWw/HachimoDock)，查看当前发布的桌面客户端与固件版本。
2. 打开 [立创硬件项目](https://oshwhub.com/eda_gqvzlprk/project_cnbmkbjc)，找到 **PCB / BOM / 3D 模型 / 装配附件**，先确认可以看到下载入口，不需要先下载全部。
3. 在 Mac 上建四个文件夹：`originals`（上游下载文件）、`working`（加工文件）、`evidence`（照片截图）、`notes`（日志）。**不要将上游资料直接再公开到本 GitHub**。
4. 阅读 [版本与来源](/projects/hachimodock/02-sources/) 的许可证提醒。
5. 在下面勾选你已有的工具；缺的先记在笔记，不用立即下单。

## 新手术语

| 词 | 意思 | 本项目的用途 |
| --- | --- | --- |
| STEP | 可编辑/测量的三维模型 | 外壳、屏幕配合检查 |
| STL / 3MF | 3D 打印与切片相关文件 | 自打印或交付代打印的结构件 |
| PCB | 定制电路板 | 固定摇杆、按键、排母 |
| Gerber | 工厂用于制作 PCB 的生产文件 | 下单前导出/核对 |
| FFC | 扁平软排线 | 连接屏幕，方向和 Pin 数很关键 |
| 固件 | 写入 ESP32-P4 的设备端程序 | 驱动屏幕、按键与通信 |
| SHA-256 | 文件校验摘要 | 检查下载包是否完整 |

## 需要用到的工具

- [ ] 已选好自己的打印路径：自有打印机 / 借用 / 代打印 / 未决定；不必先买设备。
- [ ] 如选择自己打印，已确认**真实机型**和对应切片软件；如代打印，Agent 已准备服务规格单。
- [ ] 有 USB **数据线**，不是仅充电的线。
- [ ] 能借到或购买电烙铁、焊锡、万用表、小螺丝刀。
- [ ] 有安全、通风、远离儿童的焊接空间。

## 验收

能用自己的话回答：**“我究竟在做什么？”** —— 用 ESP32-P4、屏幕和按键做一个 USB Agent 交互终端，由 Mac 上的客户端提供状态与服务。知道首先要解决的是兼容性，不是外壳颜色。

## 出问题怎么办

如果 GitHub 或立创打不开，先记录 URL 和日期，不从不明群聊网盘下载镜像。若没有焊接工具，可将焊接作为后续关卡；现在仍然能完成第 2–4 步。
