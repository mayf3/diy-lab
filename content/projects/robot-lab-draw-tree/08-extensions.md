# 扩展关｜从 AI 画家走向实体 Agent

## 目标

在 V1 **真实通过**之后，选择一个新增能力做独立项目，不把所有功能一次塞进基础教程。

## 准备

- G6 的三次运行证据与经过审查的硬件动作适配层。
- 新任务单独列采购、危险源、数据采集方式和验收标准。
- [LeRobot 模仿学习教程](https://huggingface.co/docs/lerobot/il_robots) 和 [官方 SO-101 硬件](https://github.com/TheRobotStudio/SO-ARM100)。

## 操作

1. **换笔**：做固定的两槽笔架，先让机械臂在慢速、人工看护下放回一支笔、再拿起另一支；验证笔是否持稳，换完重新确认 TCP，失败不继续画。
2. **视觉纠偏**：同一图案分别跑“不开视觉修正”和“每段完成后拍照更新”的 A/B，记录误差分布与时间，而不是只给一张好看的照片。
3. **颜料稀释**：先以水模拟，不靠近带电控制板；研究液体容器、吸水和色差度量、清洁、防倾倒，然后单独做密封防水/电气安全评审。第一版绝不无人值守操作液体。
4. **抓取整理**：将水彩任务切换成“识别红色积木→抓取→放左盒→拍照核验”，先静态场景与慢速小物；确认夹爪力度和掉物风险。
5. **模仿学习**：额外购 leader（齿比不同于 follower），按 LeRobot 收集示范，再研究 ACT/SmolVLA；记录示范数、成功率、硬件损耗、GPU 成本，并和确定性流程对比。
6. **复杂 Agent**：GPT 仅负责分解和工具路由，低层驱动仍为可中断的确定性程序；引入任务状态机、审计日志、工具许可、人工门和回归套件。

## 验收

- [ ] 每个新增能力都有单一可观察目标、安全检查和基线 A/B。
- [ ] 对“已经能做什么”“还做不到什么”分别记录真实证据。
- [ ] 未经现场安全验证不自动扩展到高频操作、热源、尖锐工具或儿童同场无保护互动。

## 出问题怎么办

如果扩展要求更大负载、精确力控或高速动态任务，停止在 SO-101 上硬凑；重新评估机械臂硬件是否合适。文章中的工业 xArm 7 与 SO-101 不属于同一性能等级，不能直接复制其性能叙述。
