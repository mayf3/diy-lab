# G6｜三次画树验收、问题记录与视频

## 目标

用**证据**回答“这个 DIY 是否真的完成”，而不是只看一张成功照片。制作和视频均尚未进行。

## 准备

- G0–G5 的原始文件：笔画 JSON、dry-run 报告、相机标定、校准与型号/版本记录。
- 三张全新 A5 纸，同一种水性笔，固定光照和机械臂底座。
- 相机能拍到画面和工具工作区；不在公开仓库放可识别家庭/儿童照片。

## 操作

1. 启动前检查断电开关、桌面固定、相机视野、工具夹、限速和工作区；确认环境无人闯入，操作员始终在场。
2. 在**相同任务、相同纸面位置、相同相机位置**下，依次执行 3 次 V1 画树，每次均经过干跑/人工确认/画完照片。
3. 每次在私有日志记录：运行编号、日期、LeRobot 版本、舵机/电源型号、纸区尺寸、笔尖高度、任务 JSON hash、程序版本、人工中止与否、完成时间、轨迹偏差（如可测）、是否可识别树形。
4. 在图像上检查：纸是否被划破，树干是否存在，树冠是否闭合或可辨，是否出现明显越界、错误抬笔、断笔；用真人判断和可复核的照片交叉检查自动评价。
5. **失败也计入分母**。如果第 2 次失败，要保留原因、修改前后差异，再重跑 3 次同配置验收。不要只保留最成功的一张图片。
6. 视频建议分镜：一句话任务 → 打印 SO-101 → 电源/校准 → 空跑 → 正式落笔 → 前后对比 → 失败与反思。项目网站仅登记公开且有权使用的成片链接。

## 验收

- [ ] 有至少 3 次连续真实运行记录，全部没有安全事件、越界和纸面损伤。
- [ ] 至少 3 张画作及原图可复核；在确定的一致标准下计算成功率，不能用“看起来不错”替代。
- [ ] 可重复执行的代码版本、参数、BOM 实际支出和失败日志齐备。
- [ ] **只有证据齐备且回填状态/日志后**，才讨论把项目从 `preparing` 改为 `verified`。

## 出问题怎么办

- 机械或电气风险发生：立即停止、断电，问题未定位前不复测。
- GPT 改变笔画太大：固定随机性/保存原始任务计划，并分开评价“计划变化”和“机械偏差”。
- 成功率低：把失败归因到识别/路径/机械/纸面接触之一，每次只改一个变量，重新跑整组试验。
- 录像与实际测试日志不一致：以原始测试日志和照片为准，视频不得冒充无中断的一镜到底。
