# AI Robot Lab 01｜让 GPT 指挥机械臂画出一棵树

> **状态：准备中（2026-11-07）｜尚未采购、没有实物测试。** 本页是可执行任务书，不是已经完成的成功教程。关联 [Issue #3](https://github.com/mayf3/diy-lab/issues/3)。

## 最终要完成的作品

一句话：“画一棵简化的秋天树。” GPT 只生成符合格式的**笔画计划**；本地程序检验计划、按纸面标定换算、经碰撞/速度/工作区检查后驱动 **SO-101 从臂**用水性笔在固定的 A5 纸上作画；固定相机拍照，自动判断是否画出树干和树冠。

本项目做的是 **感知 → 计划 → 安全执行 → 结果检查** 的实体 Agent，**不是**让语言模型直接发送舵机角度。初版绘画控制需全程有人在场；“睡觉时自动工作”属于后续高风险阶段，不在 V1 范围内。

### V1 可测的完成条件

- [ ] 单臂完成装配、配套电源核对、官方校准，留存版本与设备照片。
- [ ] 固定在桌面的 A5 纸上，预先校验的笔画至少包含树干 + 树冠，能被人辨认；先完成**离纸干跑**再下笔。
- [ ] 从中文任务生成结构化笔画 JSON，离线校验不合格时**拒绝执行**；任意文字都不能变为未经审核的 Python/电机命令。
- [ ] 确保每次执行前人工确认、固定臂底座、限速、笔尖柔性接触、外置断电/急停；手不进入工作区。
- [ ] 相机保存作画前后画面和判定结果；至少连续 3 次重复，逐次记录成功/失败和误差。未实测前不声称通过。

## 我已有和仍需确认的条件

- 已有：**Bambu P1S**、软件/AI 开发能力；可打印自己设计的笔架与相机支架。
- 未确认：是否已有兼容的 SO-101 舵机套件、相机、合适的实体断电装置、可供运动的固定工作台。
- 先买**单条 follower** 足以完成画树。第二条 leader 是日后做示教与机器人学习的增量采购，**不作为 V1 必需项**。
- 参考价格：上游 SO-101 作者原料表单从臂约 **¥682.23**，不是国内到手价，不包含自主打印件、相机、笔架、安全部件、人工和物流。项目总价未锁定；付款按 G1 门禁。
- 关键局限：SO-101 是低成本舵机臂，**没有默认的可靠笔尖力控**。不能从示意图推断它可以直接安全地在纸上施压；柔性笔架、接触高度、可达性需试验确认。
