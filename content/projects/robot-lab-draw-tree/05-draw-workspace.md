# G4｜从关节空间到纸面：做笔架、标定和离纸干跑

## 目标

把一支水性笔稳定固定在夹爪，建立一个**可达且不碰撞**的安全画图区域。先走空中轨迹，再小面积试画；没有力传感器时不追求画面完美。

## 准备

- 已通过 G3 的 SO-101 follower、稳定的桌面固定夹具和可立即断电的装置。
- A5 纸、纸夹/画板、小号水性笔、尺子、俯视 UVC 摄像头；P1S 打印少量**自制**笔架件。
- FreeCAD/任意可测量 CAD、Bambu Studio；可参考 [上游 MuJoCo/URDF 模型](https://github.com/TheRobotStudio/SO-ARM100/tree/main/Simulation/SO101)。
- 还没有实物，纸面高度、夹爪尺寸、工具中心点和运动范围**全部待测**。

## 操作

1. 把画纸夹在桌面，标出一个候选 **80×80mm** 的绘图正方形。先检查采购前 G0.5 的仿真报告，再通过本地安全执行器在无笔、低速、有人看护下做小幅点动，确认纸面角点；**不要手动强掰带减速器的舵机臂**。80mm 是软件目标，并非 SO101 机械性能保证，达不到就缩小画区并修改计划约束。
2. 给夹爪设计能夹稳细头水性笔的可拆卸笔架，笔垂直于纸面且允许少量轴向柔性形变（弹簧/柔性结构）。第一版只打印笔架小样，不直接复制未核实兼容性的网上 STL。
3. **避免硬碰硬**：先离纸 15–20mm 做干跑；接触高度通过纸面标定、柔性笔架和受控的小步低速测试确认，先在废纸上试画。不要用手向下压笔或让电机持续顶住纸面；SO-101 没有默认的可靠笔尖力控。
4. 固定俯视相机，拍一张包含整张纸和至少四个定位点的照片。用 OpenCV 标出纸角/标定点，根据实际物理测量估计纸面到相机像素的变换；先只处理平面 XY，工具高度单独标定。
5. 在软件中定义安全区域：可达纸面 ROI、最高/最低笔尖高度、最大速度、关节限位、避障包围盒和最大任务时间。关节空间→末端位姿运动学不能凭 GPT 猜；用官方模型+数值 IK/测试或适合该版本的已核查库。
6. 用 G0 的 `demo_plan.json` 把归一化 `[0,1]` 笔画映射到可用 ROI 的毫米坐标；所有笔画先变成分段的 `pen_up → move → pen_down → draw → pen_up`，每段先做离纸干跑并检查路径是否越界。
7. **人工批准**之后在纸面中央画直线、V 字、树干与树冠，逐项测量：笔有没有断线/划破纸、纸张是否滑动、是否出现未预期抬笔。异常立即中止并退回到小轨迹测试。

## 验收

- [ ] 固定夹具、柔性笔架、纸面 ROI、相机标定和断电装置都有现场证据。
- [ ] 全路径离纸干跑不撞桌面/相机/支架，检查结果记录。
- [ ] 能在监督下画小直线和三角轮廓，不撕纸、不失控；尚未满足时**禁止**接 GPT 自动调度。
- [ ] 全程没有手动强掰关节或依赖电机硬压纸面；异常时可立即物理断电。

## 出问题怎么办

- 笔尖压力太大：立刻中止，增加被动柔顺/减小接触位移；不能盲目提高电机扭矩。
- 纸面坐标偏移：检查相机支架移动、纸角测量/透视变换与 TCP（笔尖）标定。
- 角点不可达或关节接近奇异位形：缩小/搬动画区、更换固定位置；不得通过关闭限位来“解决”。
- 机械臂断电后关节不易移动：不要强行手掰；按官方机械结构说明处理，优先使用仿真和低速受控点动。
- 相机识别被手遮挡：暂停机器人，清空工作区后重新拍摄。
