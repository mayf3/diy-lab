# G2｜用 Bambu P1S 打印并组装 SO-101

## 目标

完成 SO-101 **单从臂**机械结构件和基本装配；先测打印精度，再一次只装一个关节。**本章为上游操作路线整理，尚未由本项目实测。**

## 准备

- G1 审核后的全套 Follower 电机、控制板、供电、螺钉、固定夹。
- Bambu P1S + Bambu Studio；优先 PLA+（原项目推荐）、已校准打印机。
- 官方 [SO-101 STL 和打印说明](https://github.com/TheRobotStudio/SO-ARM100#printing-the-parts)；[官方逐关节装配](https://huggingface.co/docs/lerobot/so101)。
- 小号十字螺丝刀（#0/#1）；必要时用镊子清除支撑，不强行掰电机壳。

## 操作

1. 下载或克隆官方仓库并记下 commit SHA；进入 STL 目录，选择 **SO101 / Follower** 对应零件，不选 SO100 或 Leader 组件。
2. **量规先行**：先打印官方 `Gauges` 文件夹中与 STS3215 对应的装配量规；拿实体舵机试配。过松/过紧先调整流量或 XY 尺寸补偿，再开始整臂打印。
3. 官方建议初始参数：PLA+、0.4mm 喷嘴/0.2mm 层高、约 15% 填充；P1S 上先按模型姿态检查支撑和螺丝孔，禁止原样照搬未检查的切片。
4. 打印底座、大小臂、腕部、从臂夹爪、控制板支架。打印完成后先拆支撑、清理孔位，**不要用加热或硬挤改变电机固定面尺寸**。
5. 先按 [G3 的“逐台设置电机 ID”](/projects/robot-lab-draw-tree/04-bringup/) 对每只电机标记 `F1–F6`，以免装进结构后搞混。**设置 ID 时一条总线只接一只未配置电机**。
6. 严格跟随官方图片/视频的关节顺序：底座 → 肩 → 肘 → 腕 → 夹爪；每装一关检查行程、线材余量、螺丝和齿轮与外壳是否干涉。
7. 固定底座到工作台，理线并检查所有关节在无电/手动可安全检查的范围内是否干涉（不要强扭带减速器舵机）；线缆避开转轴与夹爪。
8. 接电前给每个部件拍型号照片，和 G1 采购表逐行对照。

## 验收

- [ ] 打印量规与电机可合理配合；记录所用材料、切片参数、实测偏差。
- [ ] 六个从臂关节/夹爪机械装妥、无卡线与明显碰撞；整臂底座固定牢靠。
- [ ] 电机标记 F1–F6、供电版本和控制板拍照留证；**此时不宣称已通过通电运动测试**。

## 出问题怎么办

- 螺丝孔太紧：先看切片/支撑残留，不要用大扭矩强行拧入。
- 机械结构装反：对照官方逐关节图回退当前关节，别通电试错。
- 找不到从臂文件：重新确认官方当前目录、文件名和 commit SHA；上游目录结构可能变化。
- 夹爪抖动、线绷紧：**先断电**，排查线材绕轴与装配顺序。
