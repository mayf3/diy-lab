# AI Robot Lab 01｜SO-101 机械臂画树｜Agent 执行规范（机器工作流视图）

> **自动生成·规范草案，未代表真实执行。** 唯一规范源：source-data/robot-lab-draw-tree/workflow.json。源资料需在执行当天重新检索；不要将下列 planned 标记为 verified。

**D（目标）**：完成一个可重复验收的 AI 机械臂画树闭环：GPT 从中文指令生成受约束笔画计划，本地执行器检查轨迹后控制 SO-101 follower 在固定 A5 纸上绘制，俯视相机拍照复核结果。。

**受众约束**：希望从零尝试机器人和具身智能的 DIY 新手；不预设拥有 Mac、Bambu P1S、摄像头、机械臂或机器人学基础。。

**禁止误解为目标**：

- V1 只用一支黑色水性笔画简化线稿，不做水彩、自动调色或颜料滴定。
- GPT 不直接发送舵机角度、不访问串口、不执行任意 Python 或 shell；V1 不做无人值守实物运动。
- 不把 SO-101 的精度、负载、力控和安全等级等同于工业级 xArm 7。
- 不未经许可复制上游 STL、STEP、PCB 或装配视频。

### A03 · 采购前 G0：离线笔画与机械臂可达性仿真

- **执行者**：agent；**依赖**：A02；**状态**：planned

- 基于官方 SO-101 URDF/MJCF 锁定模型版本，建立 A5 纸面、目标绘画区域和轻量笔夹占位工具模型。
- 对绘画区域九个采样点及树干/树枝/树冠连续路径运行 IK、关节余量、路径连续性和碰撞检查；保存模型假设、结果表和截图。
- 若缺少可运行模型、工具姿态无解、路径不连续或碰撞检查未完成，将 G0 标记 BLOCKED；不得放行 G1 付款。

- **必须由人完成/提供**：

本关不要求你操作。

- **R 遇阻条件**：若仿真不能完成或存在不可达点，先缩小绘画区域、调整纸面方向或重新评估平台；没有 G0 PASS 不采购。
