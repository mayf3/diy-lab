你不需要自己翻 GitHub README、核对原理图或判断屏幕排线。**把具体调查交给有文件和网络访问权限的 Agent**；你只做目标选择、必要的实物操作、付款和实机验收。如果没有 Agent，仍可以点击每一关的详细教程按传统方式进行。

**目标**：完成一个可重复验收的 AI 机械臂画树闭环：GPT 从中文指令生成受约束笔画计划，本地执行器检查轨迹后控制 SO-101 follower 在固定 A5 纸上绘制，俯视相机拍照复核结果。。
**完成标准**：单条 SO-101 follower 完成装配、供电核对与校准；在固定 A5 纸面上由人工批准完成三次可复现的树木线稿绘制；每次都有轨迹、日志和前后照片，视觉验收结果可复查。。

**这一关要拿到：** 在付款前验证离线笔画格式，以及 SO-101 是否有可能在目标纸面区域内保持笔尖姿态并连续画树。。

你亲自做：

本关不要求你操作。

**怎样判断：** 离线校验通过；官方模型、工具占位、九点 IK、关节余量和整条树形路径均有可复查结果。模拟仅降低采购风险，不代表实物通过。。**当前证据状态：planned**（未运行不能算通过）。

### 第 5 关｜人批准采购并核对实收物料

**这一关要拿到：** 由人对精确 SKU、总价和风险做最终决定，并在收货后核对真实物料。。

交给 Agent 完成：

你亲自做：

- 查看 Agent 提供的 BOM、G0 报告、卖家答复、运费和总预算；明确决定是否购买。

**完成时应该有：** 明确的人类采购决定、去隐私的实收型号与数量记录、实际到手价。

### 第 6 关｜打印、装配、LeRobot 校准与安全点动

**这一关要拿到：** 把单 follower 组装成可被 LeRobot 识别和低速控制的实体设备。。

交给 Agent 完成：

Agent 提供匹配当前版本的安装和校准步骤；你负责打印、组装、接线、首次通电和现场安全检查。

你亲自做：

- 按官方结构和打印路径制作、装配并固定底座；检查线缆不会被关节夹住。
- 核对电机与电源版本，设置物理断电开关，按官方流程逐个设置电机 ID 并校准。
- 在无人/宠物进入工作区的条件下做无笔、低速、小幅点动和物理断电测试。

**完成时应该有：** 装配照片与实收 BOM、LeRobot 版本、端口、电机 ID 和校准日志、低速基础运动及物理断电测试记录。

**怎样判断：** 实体设备可稳定识别、校准和低速点动；物理断电开关已实测；无异响、卡滞、底座移动或线缆干涉。。**当前证据状态：planned**（未运行不能算通过）。

**卡住或失败：** 供电参数、关节装配或电机 ID 任一不确定时保持断电；通信异常或急停失败时停止后续动作。

### 第 7 关｜笔架、纸面标定、GPT 笔画规划和受控绘制

**这一关要拿到：** 完成从中文任务到受限笔画、轨迹预览、人工批准、实体绘制和摄像头观察的闭环。。

交给 Agent 完成：

Agent 把 GPT 线稿变成经过检查的动作；你负责装笔、标定、先干跑，再亲自批准和看护绘制。

你亲自做：

- 安装笔夹、固定纸张和相机；提供夹爪尺寸、纸面测量和标定照片。
- 先做离纸 dry-run，再做短直线和三角形小样；确认笔尖接触、纸张固定和安全范围后，人工批准第一幅树形线稿。
- 全程观察实体运动，发生异响、碰撞、卡滞或压力异常立即物理断电。

**完成时应该有：** 笔夹和纸面工装尺寸/照片、受限 SVG/JSON、轨迹计划与安全校验报告、作画前后照片和视觉比对结果。

**怎样判断：** dry-run 和小样通过；人工批准后完成一幅树形线稿；相机标定和结果对齐可复查。。**当前证据状态：planned**（未运行不能算通过）。

**卡住或失败：** 笔尖姿态、接触压力、坐标映射或路径安全任一未确认时不得接入 GPT 实体执行；退回小轨迹测试。
