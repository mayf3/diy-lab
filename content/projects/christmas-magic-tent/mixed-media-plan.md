# 圣诞魔法小屋｜2D + 3D + 智能灯光：从效果图到实体

> **设计目标图，非实拍或实物验收**。保留已选定的 165cm 实木杆 apple 小熊双门帘无垫帐篷；电子灯光与帐篷主体物理分离。

[打开高清效果原图](/media/christmas-magic-tent/concept/christmas-magic-tent-concept-full.png)

## 目标

2D 打印机做大面积A4拼接圣诞树及雪景；Bambu P1S 做星星、雪花、铃铛、礼物和装饰板支撑；WLED预装成品控制器+5V预焊寻址灯串实现动态效果。所有装饰安在独立轻质背板/支架上，不遮挡帐篷门窗；节后可整体拆下收纳。

## 按步骤制作

| 阶段 | 人的操作 | 验收条件 |
|---|---|---|
| 1. 到货量尺 | 实测帐篷侧墙、门窗、净空及房间动线 | 确认独立背板摆放，不用图片估量 |
| 2. 2D打印 | 确认 A4 拼接图的最终尺寸、边缘搭接后打印 | 样张尺寸与配色正确 |
| 3. 3D打印 | 先打印尺寸样件，再打印树顶星、雪花、礼物及卡扣 | 尺寸合适，无尖端和易脱落小件 |
| 4. 独立装饰板 | 2D拼图贴到独立背板，立体装饰固定在背板上 | 不在帐篷布或杆件上贴胶、钻孔或挂载 |
| 5. 装饰收口 | 红绿三角旗、雪花和礼物保持轻量可拆 | 不挡出入口和通风，儿童不能拉扯 |
| 6. 低压灯光 | 匹配预制5V WLED控制器/独立寻址灯串 | 商家证实电压与接头+5V/GND/DIN线序，成人低亮度验收 |
| 7. 软件灯效 | 配置WLED场景、亮度与电流限制；再连Button Deck | 手机/脚本可切换和关闭，不需增加焊接电路 |
| 8. 安全与收纳 | 验证独立支架稳定、无线束绊倒、拆卸方便 | 电子装置取走后，帐篷可以原样使用 |

## 证据边界

效果图中看起来挂在屋顶或实木杆上的装饰与灯光**仅用于呈现视觉气氛，不是安全施工方法**。实际设计应由独立落地背板承载大面积装饰，灯串/控制器供电放在儿童无法拉扯处；不可以把灯和导线缠在木杆、门帘或儿童通道上。

当前**尚未有**对应大面积装饰板的最终A4拼接打印文件、精确背板尺寸及 STL，也没有儿童安全实测；需要帐篷到货测量后开发。不把PR #20里独立小树的STL误认为本大面积装饰。
