# AI 圣诞魔法小屋｜KURA 真实卧室适配 v1

> **当前可执行设计基准（2026-11-17）**：以用户新提供的卧室实拍为依据，**宜家 KURA 低床 + 四柱水平开放框架 + 已安装蚊帐**。床后面是窗户与窗帘；前方紧挨一张大床。墙面、地面和床旁独立家具**没有已确认的空余安装空间**。原来的 60×90cm 森林展示板、展示桌、壁挂圣诞窗、独立大树、床顶布篷全部停止进入当前安装/采购清单。
>
> **证据界限**：用户实拍是位置与占用的观察，不是精确尺寸/承重/电气测量。公开仓库**只存匿名文字约束，不上传原始卧室照片**。此页是设计与验证计划，**尚未安装、接电或完成儿童使用安全验收**。

## 目标

在**不增屋顶、不遮窗、不破坏蚊帐、不占新增地面/墙面空间**的情况下，使 KURA 小床自身更有圣诞气氛，并为后续床外独立的低压灯效与实体按钮互动保留接口。优先保留现有床、蚊帐、睡眠和成人床通道；视觉华丽程度不能凌驾于安全与可达性。

## 现场布局与禁区

| 区域 | 目前能确认什么 | 当前是否作为安装位 |
| --- | --- | --- |
| **A 小床睡眠区** | 低床与床品实际在用；孩子睡觉 | **不可**布电线、挂硬件、散落小装饰、可缠绕带 |
| **B 蚊帐网面与顶部带** | 现有浅蓝蚊帐覆盖小床上部并可见透明网 | **不可承重、不可固定灯串/绳圈**；保留开合、透气、拆洗 |
| **C KURA 前侧可见木栏** | 蚊帐前可见一段木横梁 | **只可作为视觉定位参考**；未来无损布饰须核实净空、脱落、孩子拉拽、说明书限制 |
| **D 后方窗户/窗帘** | 床后主要是窗而非墙 | **不可**假定可悬挂展示板、粘贴窗纸、遮挡采光/窗帘活动 |
| **E 前方成人床/过道** | 大床就在小床前方，空间紧 | **不可**假定能摆 60×90cm 展示板、脚凳、圣诞村桌、外置大树 |
| **F 房间其他位置** | 未拍到可核实的稳定灯具安放处及投射面 | **HOLD**：设备不选型、不采购，先做低成本位置验证 |

**几何硬约束**：KURA 型号参考外形 209×99×116cm，使用低床模式；**没有斜屋顶/三角梁/顶盖**，不可因“圣诞小屋”名称生成房顶、平顶木板或高床梯子。蚊帐不等于可供装饰承重的顶棚。

## 推荐方案：床体圣诞氛围 + 床外电子效果

### V1：先有圣诞感，不采购新结构

- **主色由床品实现**：使用或替换适合儿童的深绿色/红色/米白色被套、枕套等现有可用软装；优先一件显眼的圣诞树或雪花图案，避免增加多件零散小挂饰。
- **不织布小样**：从已设计的 SVG 缩小做两三个大块、无硬件、无线绳的圣诞树/雪花轮廓，先用 A4 纸在**成人监督的白天**靠放在床外侧，比对从成人床视角是否可见；**睡前撤下**。没确认合法且无损的安装方式前，不把样板绑到 KURA 或蚊帐上。
- **PETG 资产继续留档**：星星/小屋 STL 与切片记录均可复用，但**不默认打印、放到床里、挂在木梁或蚊帐上**；如果未来有安全的已有外部家具面，再做独立摆件。
- **优先“外观见效”而不是“零件越多越好”**：从大床对面看，小床本身有连续的深绿、红和白色圣诞主题，且蚊帐开合、透气和进出不受影响，才算 V1 成功。

### V2：电子灯效——先验证床外设备位置

希望保留**可切换的圣诞暖光/缓慢雪花/星空**场景，但必须为**床外一体化、独立供电、成人可关闭**的投射灯/氛围灯；不将灯带、电线或挂饰装在 KURA 木梁、蚊帐或枕边。

| 候选体验 | 必要条件（未满足不购买） | 验收 |
| --- | --- | --- |
| 温暖圣诞模式 | 已有稳定且远离床铺的家具面；灯具不会被孩子碰倒或拉线；照射不会直射眼睛、窗外或邻居 | 成人在睡觉模式前可以一键熄灭 |
| 缓慢雪花/星点投射 | 有适当的投射面和摆放距离；不遮挡窗/窗帘和出入通道；实际使用低眩光、无频闪设定 | 实拍日/夜效果，保证没有照向孩子脸部 |
| 原有台灯补光 | 确认现有可用灯具与安全插座位置，电线不能伸入儿童可触/可缠区域 | 电线收纳和关机方式均经过现场检查 |

**当前不推荐**把电池灯串缠到网布上，或用临时支架在床旁过道架投影仪。普通 USB / 低压不自动意味着适合靠近儿童或布艺；发热、电池仓、拉拽、供电与成人操作都需核实。

### V3–V4：互动，不抢 V1 施工

- **V3 实体按钮**：复用已有 Button Deck / ESP32 项目的设计思路，但目前独立电子盒与放置位置均为待定。先做桌面按钮→模式控制概念，再经现场电源与收纳验证；PIR 仅可选，避免夜间突然高亮/声音唤醒。
- **V4 GPT 故事**：手机/电脑的**按住说话**形式，成人可随时停止；先通过已有设备播放故事，不引入床边常开麦克风或隐藏线路。
- 原帐篷时期的 WLED/UNO/PIR/DFPlayer 接线图**不能直接搬到蚊帐床上**；兼容性、功耗、限流和外壳另外审查。

## 首个可以执行的制作与验收

| 顺序 | 拿什么 | 做什么 | 看到什么才通过 |
| --- | --- | --- | --- |
| 1 | 现有蚊帐/KURA/床品 | 不动装饰，查看蚊帐的进出、拆洗及大床侧通行 | 两张床的基本使用完全不受限 |
| 2 | A4纸、剪刀和尺子 | 仅剪一组小树/雪花大轮廓，成人**白天**在小床外临时靠放拍比大小 | 从大床方向一眼看出圣诞主题，且不占床内/过道 |
| 3 | 现有或待确认的布料 | 仅在有安全位置后做1件大面积软质装饰，必要时改为节日床品 | 能快速移走、无挂绳/小散件、不接触蚊帐 |
| 4 | 已有台灯/手机 | **仅在找到外部稳定位置后**测试照明/故事，不新增电器安装 | 无线材进入睡眠区，成人能关闭，孩子无眩光/误触 |
| 5 | 手机相机 | 记录白天与夜间的装饰效果（只在私有工作区留存） | 视觉清楚、不影响睡眠与窗帘/蚊帐功能 |

**第一阶段不要求**打印39页森林纸样、购买 60×90cm 泡沫板、切片打印两座小屋、购买投影仪或控制板；这些属于保留的数字研究资产，不是目前有效采购清单。

## 验收

- [x] 已根据用户实拍收敛：后方窗、前方成人床、现有蚊帐、无空墙/新增展示空间。
- [x] 本页面不包含斜屋顶、高床安装、墙面大展板、独立展示桌或床上电气安装作为执行步骤。
- [ ] 已确认蚊帐完整开合和床边通行空间，记录**无私人信息**的量尺/示意。

- [ ] 如继续 V2：已确认独立灯具的稳定现有摆放位置、投射角与可收纳线缆，再决定选型、购买与实际测试。
- [ ] 真实设备或装饰实物测试有成人现场核验；没有照片/日志不写“已安装”。

## 出问题怎么办

如果找不到安全安装/摆放位，**不要强行加挂件、夹具、地灯或另买小桌**；V1 直接降级成圣诞床品与白天临时的纸样活动。若投影会照到睡眠者、窗外或邻居，或灯具有可触及电线/发热隐患，就取消该电气方案。若装饰会影响蚊帐开合、床垫通风或孩子上下床，立刻移除并回到原始床型。
