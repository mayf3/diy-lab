# 下一阶段：布艺、PIR、音频和独立控制盒

> **尚未提供可跟做的实体动画**。四灯桌面练习不是完整装置，PIR/声音的模拟事件更不等于真实播放。准确安装图必须根据到货的连接器、排针、电源与盒体确认。

## 目标

保持帐篷与电子模块**完全物理分离**。先完成轻量布艺，再分别测试 PIR 和音频，最后在独立盒体集成，供成人验收后交给孩子按按钮体验。

## 操作步骤

1. **布艺**：把三角旗与可缝魔术贴做成能拆下的短装饰段。不要在帐篷布上贴强力背胶，不在木杆上悬挂有重量或形成绳圈的装饰。
2. **PIR 单独测试**：看清收到的 HC-SR501 电源和 OUT 丝印；先用桌面低压电路验证上电预热、输出延时和检测范围，不能拿 PIR 当儿童安全监控。
3. **DFPlayer 单独测试**：确认实际模块的针脚、3.3–5V 输入要求、扬声器端子和 microSD 格式；用短音频验证真实输出，控制音量，避免音频峰值造成 MCU 重启。
4. **电源分配**：先用万用表检验所有分配板与线束的 **+5V / GND** 极性、共地和空载电压；再按确认后的供电设计连接每一路，禁止 USB 反灌。
5. **外壳**：根据实际板卡、按钮尾部和线材占位确定安装孔；用洞洞板或可靠端子连接、绝缘和应力释放。不要把临时面包板直接长期放到孩子活动范围内。
6. **合体**：先在独立桌面盒完成按钮灯光、PIR、声音回归。之后让灯光照向帐篷或用帐外底座呈现，不让电路与帐篷主体承力连接。

## 验收

- [ ] 布艺可无损拆除，不影响出口和通风
- [ ] PIR 真实模块及声音的单独测试已有照片或日志
- [ ] 正负极、线束连接、音频音量和长时温升均已检查
- [ ] 控制盒稳定、绝缘、线缆有应力释放，儿童无法拉扯
- [ ] 电子模块拆走后帐篷仍能正常使用及收纳

## 出问题怎么办

无真实电气接线表或端子极性不明确时 **HOLD、不通电**；听到杂音、反复重启、发热、异味或发现裸露金属时立即断电，由成人检查或找有经验者协助。后续会把这些真实步骤扩展为像第一关一样逐帧的动画，而不是用模拟展示代替测量。
