### 交互验证：已通过（2026-11-07，Brave 真实浏览器补验；此前自动化受阻经过留档如下）

**自动化尝试与受阻原因**：鼠标合成点击（cua.click/drag）与合成键盘事件均未触发模式切换；截图测量确认 **Wokwi 仿真时钟在本环境停滞**（速度指示 0%、CPU 0%、rAF 驱动停摆）——任何 down→up 间隔在停滞的仿真时间里都是 0ms，被 30ms 去抖吞掉。这是浏览器无头化环境的限制，不是固件或接线问题。已把按钮配置为键盘快捷键 **Q**，在正常前台浏览器里即可验证。

**人工复现步骤（预计 5 分钟）**：

1. 打开 <https://wokwi.com/projects/new/arduino-uno>
2. tab 栏 ▾ → New file… ×2：创建 `controller.h`（粘贴 `g2/firmware/controller.h` 全文）与 `controller_idle10s.h`（粘贴 `g2/firmware/controller_idle10s.h` 全文）
3. sketch.ino 替换为 `g2/firmware/ChristmasStar.ino`；diagram.json 替换为 `g2/wokwi/diagram.json`（已含 `"key":"Q"`）
4. 运行 → 首次弹 "Build failed" → 点 **INSTALL "ADAFRUIT NEOPIXEL" LIBRARY** → 再次运行
5. **点击电路图区域聚焦，然后敲键盘 Q**（每按一次 = 一次完整短按）：
   - 灭 → 单击 Q → 4 颗暖橙（串口 `Mode: 1`）
   - → 再击 Q → 彩色循环（`Mode: 2`）
   - → 再击 Q → 全灭（`Mode: 0`）
   - 点亮后**按住 Q ≥1.2s 再松开** → 直接回灭，且松手不再切换
   - 上电瞬间按住 Q → 不得点亮
6. 超时可视化（可选）：sketch 换成 `wokwi/SimTimeoutTest.ino`（引 `controller_idle10s.h`），点亮后静置约 10 秒自动回 `Mode: 0` —— **仅演示用；10 分钟阈值的边界验证以主机测试 S6 为准**
7. 保存截图/项目：Wokwi 保存项目需登录 GitHub/Google 账号（匿名项目无法获得直链）；登录后 SAVE 即得可分享直链

## 出问题怎么办

- **Wokwi 编译报 `Adafruit_NeoPixel.h not found`**：Build failed 弹窗点蓝色 INSTALL 按钮，或 Library Manager → + → 搜 "Adafruit NeoPixel" 安装。
- **敲 Q 没反应**：先单击电路图区域确保焦点在仿真面板；确认仿真在运行（右上角计时器在走）；确认 diagram.json 里按钮 attrs 有 `"key":"Q"`。也可直接鼠标点击按钮（正常前台浏览器中鼠标可用）。
- **按一下 Q 模式跳了两档**：键盘自动重复（长按 OS 重复触发）——敲击要干脆，或改用鼠标点击。
- **host 测试编译失败**：需要 C++11 以上（macOS 自带 clang 即可）；`test_controller.cpp` 原版测试的 include 是相对教程目录结构，放回 `qa/` 同级 `03_Arduino/` 再编译。
- **SimTimeoutTest 里 10 秒就自动灭**：预期行为（IdleMs=10000 演示版）；生产固件是 600000ms。
- **实物板不是 UNO**：停。先拍照确认型号，再由下一关决定移植或换基线；勿直接套用接线。
