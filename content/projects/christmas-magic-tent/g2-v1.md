### 人工复现步骤（Wokwi）

1. 打开 <https://wokwi.com/projects/new/arduino-uno>
2. tab 栏 ▾ → New file… → 创建 `controller.h`，粘贴 `g2/firmware/controller.h` 全文
3. sketch.ino 替换为 `g2/firmware/ChristmasStar.ino` 全文；diagram.json 替换为 `g2/wokwi/diagram.json` 全文
4. 运行 → 首次弹 "Build failed" → 点 **INSTALL "ADAFRUIT NEOPIXEL" LIBRARY** → 再次运行
5. 验证：上电 4 灯灭 → 单击变暖橙（Mode 1）→ 再击变色相循环（Mode 2）→ 再击回灭 → 按住 ≥1.2s 从亮到灭 → 松手不切换 → 每次模式变化串口打印 `Mode: n`
6. 超时加速验证（可选）：把 sketch 换成 `wokwi/SimTimeoutTest.ino`（时钟 ×60），点亮后静置约 10 秒观察自动回 `Mode: 0`，串口显示 `virtual_ms≈600000` —— **此草图仅测试用，生产保持原版**

## 出问题怎么办

- **Wokwi 编译报 `Adafruit_NeoPixel.h not found`**：Build failed 弹窗点蓝色 INSTALL 按钮，或 Library Manager → + → 搜 "Adafruit NeoPixel" 安装。
- **按钮点了没反应**：检查 D2 接的是按钮 `1.l`、GND 接 `2.l`（同侧引脚内部连通）；确认仿真在运行（右上角计时器在走）。
- **host 测试编译失败**：需要 C++11 以上（macOS 自带 clang 即可）；`test_controller.cpp` 原版测试的 include 是相对教程目录结构，放回 `qa/` 同级 `03_Arduino/` 再编译。
- **SimTimeoutTest 里色相转得飞快**：预期行为——渲染用真实时间、控制器用 ×60 虚拟时间，仅测试用。
- **实物板不是 UNO**：停。先拍照确认型号，再由下一关决定移植或换基线；勿直接套用接线。
