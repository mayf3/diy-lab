## 目标

在不花一分钱的前提下，回答三件事：①上一阶段的两个候选尺寸放进真实房间会不会有硬冲突；②门洞、通风窗、儿童占位、动线、电子与装饰预留各差多少厘米；③购物前必须向卖家/家里核实哪些数字。

上一阶段的候选尺寸（110×160 vs 160×110，檐高 80 / 脊高 135）停留在纸面。G0 用 Blender 把两个候选都建成**可参数化几何模型**，在假想房间里检查：门洞会不会顶到屋顶、通风窗位置、儿童占位、门口动线、电子与装饰的预留位置。**先模拟，再谈购物。**

全部文件（脚本、两个 .blend 工程、17 张渲染图、尺寸 CSV、检查 JSON）已入仓库：

- 脚本与数据：`source-data/christmas-magic-tent/g0/`（`tent_generator.py`、`dimension_comparison.csv`、`geometry_checks.json`）

## 模型主动发现的四个问题

1. **站立净空是硬限制。** 屋面从檐口 80cm 升到脊 135cm，110cm 儿童要求头顶 10cm 净空时，可站立条带仅 30cm（A）/ 43.6cm（B）宽。帐内活动以跪坐为主——这是产品形态决定的，不是缺陷，但采购预期要写清楚：**这不是能站进去玩的游戏屋**。

2. **门高 90cm < 儿童身高 100~115cm（测试范围，非实测）。** 进入必须弯腰/爬行（下方儿童视角即蹲姿眼高 0.72m 取景）；成人无法直立进出（门 90 / 脊 135），收拾与装灯都是蹲姿作业。若希望家长能弯腰进出，选型时门净高尽量 ≥100cm。

   ![蹲姿进门视角（门帘拉开状态）](/media/christmas-magic-tent/g0/A_child_entry.png)

3. **小可用区域压力测试：3.0×3.5m 是一个压力测试场景，不是通用的最小房间要求。** 该场景中帐篷本体放得下（X 净距 45cm / Y 净距 15cm），但假设的房间门扇旋转范围距帐篷角仅 **5cm**、且与门口通道**重叠**。它说明的是：同样大小的空间，房门和家具位置不同结果就不同——**帐篷尺寸不是瓶颈，"帐篷 + 门口通道 + 门扇旋转"三者合成动线才是**。复核真实房间时优先量：实际准备放帐篷的那块地面（确认 1000×1000cm 输入是真实净空还是初步模拟值）、房间门位置与开启方向、暖气与家具占位。

   ![3.0×3.5m 压力测试：门扇范围与通道重叠（俯视）](/media/christmas-magic-tent/g0/A_small_top_room.png)

4. **A 方案门口每侧仅 20cm。** 门洞上角处屋面高度恰 100.0cm，净空 10cm——真实商品若门框有上沿构件（门帘杆、包边），余量可能被吃掉。B 方案净空 20.9cm、侧边 45cm，几乎无此风险。

## 电子与装饰预留（几何占位，未做使用验证）

**设计决策：控制与电源全部外置，帐内只进低压发光件。**

> **验证边界**：以下位置仅为几何占位与可视化，**不是安装验证**。按钮 80cm 高度是否适合孩子，取决于她的实际身高、站姿和按压力；独立支架按钮还需评估按压时的倾倒风险。正式冻结按钮高度与固定方式前，先用纸板做 1:1 占位并进行人体操作测试。 控制盒 15×10×6、USB 电源 20×8×5、扬声器 12×10×8 放帐外右后；按钮立杆高 80cm（3~6 岁可及性为假设，待对孩子实测）；PIR 门楣上方；星星灯沿两侧檐口（帐内）；魔法窗为后山墙 Ø20cm 圆窗。隐藏电子层后基础小屋完整：

## 出问题怎么办

- **卖家尺寸与本页数字对不上**：以卖家为准回填 `CFG` 重跑，不要手改本页结论；差异大就把候选降级。
- **`blender` 命令不存在**：macOS 执行 `brew install --cask blender`，或从 blender.org 下载后使用完整路径 `/Applications/Blender.app/Contents/MacOS/Blender`。
- **渲染图全黑或报错**：脚本内置 Workbench→Cycles 自动降级；仍失败时加 `--skip-render` 先验证几何输出，再单独排查渲染引擎。
- **`.blend` 双击打不开**：工程由 Blender 5.2 保存，低版本可能不兼容；升级 Blender 或直接用脚本重新生成同版本场景。
- **真实房间比 3.0×3.5m 还小**：说明当前两候选都不合适，先解决房间动线（门位/家具），不要硬买。
- **孩子身高超过 115cm 或想站着玩**：两候选都不满足，需要按"门 ≥100cm、脊 ≥135cm"重新提参数（例如 H=150cm）重跑验证。

## 怎么复现

```bash
# 需要 Blender 4/5（macOS 直接 brew install --cask blender）
cd source-data/christmas-magic-tent/g0

# 方案 A（默认房间 10×10m）
blender --background --python tent_generator.py -- \
    --variant A --out . --blend-name christmas_tent_G0.blend
# 方案 B
blender --background --python tent_generator.py -- \
    --variant B --out . --blend-name christmas_tent_G0_variant_B.blend
# 小可用区域压力测试
blender --background --python tent_generator.py -- \
    --variant A --out /tmp/g0_small --room-w 3.0 --room-d 3.5 \
    --tag A_small --only top_room --no-save --no-data
```

改任何尺寸（含录入真实商品尺寸）：编辑脚本顶部 `CFG` 的 `variants` 字典与 `E/H/door_*`，重跑即自动更新模型、17 张图、CSV 与检查 JSON。
