# G2-V2｜PIR 迎宾与声音事件纯数字模拟

> **证据分层**：本页全部为【主机逻辑测试】+【Wokwi 数字模拟】；**声音是事件模拟**（串口打印 `[PLAY_WELCOME]` 等），不宣称 DFPlayer 或任何真实音频器件已验证；**不进行实物接线**。
> 日期：2026-11-07。G2-V1 的 `controller.h` 作为基线**原样保留**（本阶段零改动），迎宾逻辑为新增独立模块 `greeter.h`，两者并存不重构。

## 目标

在 G2-V1 三态灯控之上，验证 PIR 触发欢迎演出的控制逻辑：触发/冷却/防重复/手动按钮优先/上电默认。全部在数字层完成，为 G2-V3（音频器件选型）与 G4（实物）提供可复用逻辑。

## 交付物（`source-data/christmas-magic-tent/g2-v2/`）

| 文件 | 说明 |
| --- | --- |
| `firmware/greeter.h` | `PresenceGreeter` 纯逻辑类（Arduino 无关，参数可注入：冷却 15s / Welcome 3s / Story 5s 为生产默认） |
| `host-tests/test_g2v2.cpp` + `RESULTS.txt` | 6 场景宿主测试（含与 StarController 联演） |
| `wokwi/diagram.json` | UNO + 按钮 D2（键盘 Q）+ **滑动开关模拟 PIR**（D3）+ 4× WS2812（D6） |
| `wokwi/StarLightGreeter.ino` | 集成演示 sketch（两控制器并行运行，声音映射为串口事件） |

## 逻辑设计（验收口径）

| 行为 | 语义 |
| --- | --- |
| PIR 上升沿 | 触发演出事件：`Welcome`/`Story` **交替**（sketch 映射为 PLAY_WELCOME/PLAY_STORY） |
| 冷却 | 距上次**触发时刻** < CooldownMs（生产 15s）不重播 |
| 播放中再次触发 | 忽略：不重启、不排队、不打断 |
| 手动按钮优先 | 灯切到 **Off** 时演出立即挂起；Off 期间 PIR 不触发；重新点亮后需新的上升沿 |
| 上电默认 | Idle 不播放；begin 时 PIR 高电平（HC-SR501 预热）被抑制，需先见下降沿 |
| 声音 | **仅事件**：`event()` 返回 None/Welcome/Story，由 sketch 打印；无音频器件 |

`StarController` 三态灯控与 `PresenceGreeter` 完全解耦：sketch 每帧把 `controller.mode()` 作为 `lightMode` 传给 `greeter.update()`。

## Wokwi 数字模拟

`wokwi/diagram.json`：PIR 用**滑动开关模拟**（D3，HIGH=有人活动）——Wokwi 无原生 PIR 部件，开关即理想化的 PIR 输出；正式 PIR（HC-SR501 的重触发/单稳跳线、预热期）属于 G4 实物验证。

操作（在正常前台浏览器，本页不再投入自动化）：重建项目（步骤同 G2-V1，多一个 `greeter.h` 与滑动开关）→ 运行 → 敲 **Q** 点亮 → 拨动开关模拟有人进入 → 串口出现 `[PIR] motion detected` + `[PLAY_WELCOME]`，3 秒后 `[AUDIO_DONE]`；15 秒内再拨不重播；长按 Q 关灯后拨动开关无事件。

## 出问题怎么办

- **测试编译找不到头文件**：`greeter.h` 在 `g2-v2/firmware/`，测试的相对 include 以仓库路径为准，勿移动目录。
- **Wokwi 里拨开关没事件**：灯在 Off（greeter 挂起是设计行为）；或刚播完还在 15s 冷却内；或开关接的是 1/3 脚（公共脚是 2）。
- **想改冷却/时长**：改 `PresenceGreeter` 构造参数（生产默认在 sketch 的 `greeter` 定义处），不要改 `greeter.h` 常量语义。
- **真实 DFPlayer 接入**：属 G2-V3/G4；本层只保证事件时序正确，接线与供电另行评审。

## 局限性声明

模拟中的 PIR 是理想开关：无预热期、无误触发、无探测死角。事件与"声音"之间无音频链路。冷却/时长默认值为设计建议，未按孩子实际行为标定。本页不构成任何实物接线或电气结论。
