### 场景表（帐篷实价 X 是唯一变量）

| 场景 | 条件 | 总预算 | 余量 |
| --- | --- | --- | --- |
| 全必购（万用表新买、UNO 新买） | X ≤ 200 | 440 + X ≤ 640→**需砍**；即 X>60 就要动用抵扣 | — |
| **基准：借用万用表（省 40）** | X ≤ 240 | 400 + X | X=169 → **余 31**；X=199 → 余 1 |
| **理想：再复用旧 UNO（省 45，需核验通过）** | X ≤ 285 | 355 + X | X=169 → **余 76** |
| 预算破裂 | X > 285 | — | 需砍装饰/电子范围或放弃 |

> 注：基准场景 = 装饰 50 + 电子（除 UNO）105 + 运费预留 60 + 帐篷 X + 万用表 0。

## 出问题怎么办

- **京东商品页跳登录**：移动版 item.m.jd.com 可匿名看标题/SKU/服务，价格需登录；桌面版 item.jd.com 全部需登录。
- **详情图没有尺寸标注**：把详情图截图发给建模侧，按"无标注"处理，几何走 G1b 不确定性模拟的边界判定，并把实物测量列入到货验收项。
- **实价超过 ¥285**：预算破裂——回 G1a 换对照款或砍装饰/电子范围，不加总预算。
- **搜索页跳登录**（京东站内搜索必须登录）：把关键词发我，或你登录后搜一次发链接。
- **候选缺货**：主候选显示"现货"但可能变化；缺货即启用对照款流程，不提高预算上限。
