# V1 制作路线｜从效果图到可点亮的帐篷魔法小屋

> **证据分级**：效果图 = 目标设计；G0/G1/G2 = 数字/电路模拟；本页 = 施工路线。**帐篷未下单、未到货；第 1 步完成前所有尺寸都是占位参数。** 电气边界：全部低压 5V、帐外操作、与帐篷主体物理分离；PIR 与 DFPlayer 属 V2，不在本页。

**主 CTA 对应页**。路线摘要见 [2D+3D+智能灯光 8 步总览](/projects/christmas-magic-tent/mixed-media-plan/)；本页是每一步的**可跟做细节**。

## 开始前必须成立的条件（否则停在这一步）

- [ ] 帐篷已按[采购合并清单](/projects/christmas-magic-tent/consolidated-purchase-plan/)下单并**通过到货验收**（[到货验收清单](https://github.com/mayf3/diy-lab/blob/main/source-data/christmas-magic-tent/arrival-acceptance-checklist.md) 全部勾选）。
- [ ] 家庭盘点完成：旧 Arduino UNO R3（V1 不用但留作 V2）、5V ≥1A 充电头（标签核对）、针线、P1S 耗材存量 ≥100g。
- [ ] 已购：WLED 控制器 + 预焊灯串 + 背板（见 [V1 统一 BOM](https://github.com/mayf3/diy-lab/blob/main/source-data/christmas-magic-tent/v1/v1_wled_bom.csv)）。

**工具与耗材总清单**：卷尺、剪刀、美工刀、白卡纸/A4 打印纸 12 张、胶棒或双面胶、5mm 瓦楞板 1–2 张、P1S + PETG 耗材、电脑（浏览器即可，无需编程环境）、手机（WLED 配网用）。

## 第 1 步｜到货量尺（一切尺寸的来源）

- **拿什么**：卷尺、手机拍照、打印 [量尺记录表](https://github.com/mayf3/diy-lab/blob/main/source-data/christmas-magic-tent/arrival-acceptance-checklist.md)。
- **做什么**：量帐篷**侧面可用区**的净宽与净高（避开门帘与木杆）、背板预定摆放位置的地面宽度；把数字填进 `source-data/christmas-magic-tent/v1/make_a4_tree.py` 的 `TENT_SIDE_W / TENT_SIDE_H`。
- **看到什么**：两侧数字 ≥ 树冠目标 560×800mm 的 90%，否则先把 `TREE_W/TREE_H` 等比缩小再打印。
- **失败怎么办**：数字太小 → 换小一号 `TREE_W`（脚本顶部 CFG）重跑，或放弃背板贴面改为独立立式装饰板。
- **验收**：`python3 source-data/christmas-magic-tent/v1/make_a4_tree.py` 重新生成 12 页 SVG，页脚显示新尺寸。

## 第 2 步｜2D 打印：A4 拼接圣诞树图案

- **拿什么**：第 1 步生成的 `generated/a4/a4_tree_p1..12.svg`、A4 纸 12 张、打印机、剪刀、胶棒。
- **做什么**：浏览器逐页打开 SVG → 打印对话框选 **A4 纵向、缩放 100%（禁用「适应页面」）**、彩色。打印完先用页内 100mm 边框量一下确认没有缩放。按页角十字标对齐相邻页（搭接 10mm），先拼成整棵树再整体粘贴到背板上。
- **看到什么**：12 页拼出 560×800mm 分层绿色树冠 + 雪顶带；所有十字标严丝合缝。
- **失败怎么办**：页缝错位超过 5mm → 重打错位页并只用十字标对齐；颜色太浅 → 打印机选「高质量」；某页尺寸差 3% 以上 → 打印机驱动在缩放，改用「实际大小」。
- **验收**：拼好的树平贴在背板候选位置，目测比例与效果图一致。

## 第 3 步｜3D 打印：装饰件与安全固定件

- **拿什么**：`v1/generated/` 下 4 份 STL（树顶星 / 雪花 / 礼物盒 / 背板卡扣）、P1S、PETG。
- **做什么**：Bambu Studio 导入 STL → **平放打印**（背面朝下）→ PETG、0.2mm 层高、_supports 手动（树顶星内凹处少量）→ 切片预览确认无悬空失败 → 打印。卡扣先打印 1 个，用真实背板试挂。
- **看到什么**：`assembly_check.json` 记录的尺寸：星 105×100×8mm、雪花 96×86×5mm、礼物 72×42×12mm、卡扣内宽 = 背板厚 + 0.6mm。卡扣能用手劲挂上背板且不滑落。
- **失败怎么办**：卡扣太松 → `python3 make_decorations.py --board-t 实测厚度` 重跑再打印；太紧 → 沙纸修边，不要硬掰裂背板；星尖断裂 → 加支撑重印或降层高。
- **验收**：4 件实物与 json 尺寸一致；卡扣挂背板 24 小时不脱落。
- **待实测占位**：背板厚度 5mm 是假设值；真实背板采购后必须重跑脚本。

## 第 4 步｜独立背板与支架（不依赖帐篷承重）

- **拿什么**：5mm 瓦楞板 1–2 张（≈600×900mm）、第 2 步拼好的树、A 字支架材料（同料瓦楞板双层折叠或木条）、背板卡扣 ×2。
- **做什么**：树图案整体贴上背板 → 背板背面加两条竖向加强带 → A 字支架用同样瓦楞板折成三角截面 → 3D 卡扣挂在背板上缘挂装饰件（星/雪花/礼物）。**全程不在帐篷布、木杆、门帘上打孔、贴胶、挂重。**
- **看到什么**：背板独立立于地面，成人轻推两侧无明显侧倾；树顶星位于帐篷侧后方而不是压在帐篷上。
- **失败怎么办**：侧倾 → 加宽 A 字支脚跨距；背板弯折 → 加第三条竖向加强带或换双层瓦楞；地面滑 → 支脚贴防滑胶垫。
- **验收**：轻推测试通过；装饰板可整体搬走且帐篷原样可用；儿童站不到的位置放置。

## 第 5 步｜WLED 灯光接线（免焊，全程断电）

- **拿什么**：GLEDOPTO GL-MC-001WL 控制器、WS2812B 预焊灯串（20 灯 JST-SM 3Pin）、5V ≥2A USB 电源、万用表（借用）。
- **做什么**：断电状态下核对三段接口的 **+5V / GND / DIN** 丝印——电源→控制器（USB），控制器→灯串（3Pin JST，**公母配对即可插，线序仍要目视核对丝印**）。全部插好后最后才把 USB 电源插上。
- **看到什么**：控制器上电后灯串短暂全亮一下（WLED 启动自检）。
- **失败怎么办**：第一颗亮其余不亮 → DIN 方向反了，把 JST 插头翻转重插（**断电操作**）；全不亮 → 换 USB 口/换线，量电源输出 5V；只亮前几颗 → 灯串是坏段，联系卖家。
- **验收**：接线照片一张（能看清三段丝印）；全程无焊接、无裸线并接。

## 第 6 步｜WLED 软件配置（手机即可）

- **拿什么**：手机连到与控制器同一个 Wi-Fi、本仓 `v1/wled_presets.json`。
- **做什么**：手机浏览器访问 `http://<new-device>` 进 WLED → Config → Wi-Fi 设固定地址 → LED Preferences：选 WS281x、灯珠数 20、**电流限制 700mA** → 按预设表手动建 5 个预设（全灭/暖光低亮/慢闪/彩虹/呼吸）或上传 presets.json → 用 `curl http://<ip>/win&P1=1` 验证切换。
- **看到什么**：4 个预设逐个生效，亮度都不刺眼（≤64/255）。
- **失败怎么办**：颜色红蓝颠倒 → Config 里把色彩顺序 GRB/RGB 对调；预设切换无效 → 检查预设编号 0–4 是否保存成功；找不到设备 → 用路由器后台查新设备 IP。
- **验收**：手机不开 App 也能用浏览器切预设；断电重启后预设仍在。

## 第 7 步｜组装与最终验收

- **拿什么**：全部前 6 步成果。
- **做什么**：背板放到位 → 低亮度暖光预设 → 成人做四项检查：①轻推背板不倒；②帐篷布/门帘/木杆上没有任何新增粘贴或悬挂；③电线全程在儿童不可拉扯位置；④断电开关可被成人一键切断。
- **看到什么**：帐篷+背板+灯光整体成立，与效果图目测一致（差异记录进 13-log）。
- **失败怎么办**：任何安全项不过 → 撤掉电子件，只保留静态装饰，回改支架。
- **验收**：勾完即 V1 完成；拍照留证（不含儿童正脸与家庭环境隐私）。

## 第 8 步｜拆卸与收纳（节后）

- **拿什么**：无。
- **做什么**：断电 → 3D 件与背板整体搬离 → 灯串绕盘收纳 → 卡扣拆下装袋 → 帐篷按原厂方式折叠收纳。
- **看到什么**：帐篷无孔、无残胶、无压痕，可正常二次使用。
- **失败怎么办**：魔术贴残胶 → 除胶剂少量试擦（先在隐蔽处）；杆件受潮 → 干燥后收纳（南方潮湿气候按到货清单的收纳节处理）。
