# 照片、视频与模型文件：怎样长期整理？

## 一、仓库里放什么，仓库外放什么

| 内容 | 建议存放 | 原因 |
| --- | --- | --- |
| 自己拍的小尺寸照片、封面图、缩略图 | `public/media/项目名/` | 页面可以直接引用，建议压缩到单张 1MB 左右 |
| 自己写的 Markdown/CSV/代码/清单 | `content/`、`source-data/` | 易比较、易维护 |
| 自己制作且有权分享的 STEP/STL/3MF | `source-data/项目名/files/`（新建） | 小体积可进 Git；注明版本和打印测试 |
| 数 GB 原始视频、4K 录像 | 本地存储/网盘/视频平台 | 不要塞进普通 Git 历史 |
| 成片 | B 站、YouTube 等 | 页面放链接或嵌入，保留发布日期 |
| 第三方上游 STEP、PCB、视频、素材 | 官方原始链接 | 许可证不明时不直接转载 |
| 采购订单个人信息/API Key/家庭照片隐私 | **不要上传公开仓库** | 避免不可逆公开 |

## 二、建议的素材命名法

```text
2026-11-06_hachimodock_04-ffc-check_01.jpg
2026-11-06_hachimodock_06-first-print_01.mp4
2026-11-06_hachimodock_10-final-front_01.webp
```

建议每张关键图附一句“这张照片证明什么”，拍摄日期、材料版本和是否经过实物验证。

## 三、拍什么才能真的教会别人？

对每个实际操作步骤，尽量拍：**开始前的材料状态**、**手部操作过程**、**完成后的检验结果**，对于需要方向/极性的连接器还应拍清局部标记。`HachimoDock` 的 [拍摄分镜](/projects/hachimodock/12-video/) 已提供完整示例。

## 四、视频发布后，如何回到教程？

在项目 `index.md` 放视频地址；在对应的章节补充精确到秒的时间码，例如“视频 02:10–02:44：装排母”；在 [制作日志](/projects/hachimodock/13-log/) 记录视频修订日期。**没有成片前不要写“点击观看实测视频”。**

## 五、版权、孩子隐私和平台规则

自制图片可以上传前先检查是否包含孩子的正脸、学校标识、门牌、精确位置、电脑个人账户/聊天记录、API Key。涉及家庭和孩子的内容默认只保留不识别身份的细节图。第三方资源与视频不得仅凭“能下载”就复制发布，参见 [许可和来源声明](/guide/legal/)。
