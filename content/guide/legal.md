## 对证据采用的写法

| 标记 | 表示什么 |
| --- | --- |
| 官方资料 | 来自上游官方原始文档，应附链接与查看日期 |
| 参考价 | 页面显示过的价格，不是实时成交价 |
| 计划 / 预计 | 还没操作、尚未验证的假设 |
| 待核实 / HOLD | 阻塞下单或进入下一关的问题 |
| 实测通过 | 有设备/材料/步骤/结果和时间的测试 |
| 实测失败 | 有具体观察结果的失败，允许复现 |

## 变更规范

产品版本、链接、固件可能更新。改变型号或关键步骤时，同时更新 `data/projects.json`、对应教程的“已核实资料基线”及实测日志。不要在没有证据时说“已经验证过”“零风险”。
