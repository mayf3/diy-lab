# 有 AI 助手的 DIY：第一次也能跟着做

> 本页给**所有人**，不以拥有 Bambu P1S、Mac、焊台或工程背景为前提。Maker Lab 不承诺任何设备“包成功”；会把已确认的资料、还未验证的假设和真实制作结果分开。

## 从你希望做出的东西开始，而不是从工具开始

第一次做 DIY，你通常只需要告诉 AI 助手四件事：

1. **想做什么**：例如“我想复刻 HachimoDock，能在桌面显示 Agent 状态”。
2. **有什么**：电脑操作系统、有没有 3D 打印机或电子工具、最多愿意花多少钱。不知道某个设备的型号也没关系。
3. **愿意亲自动手到什么程度**：要不要焊接；是否愿意借用机器或找代打印服务。
4. **先不要做什么**：例如“先核实商品再付款”“不允许替我下单”。

这是**资源分流**，不是入门考试。后面的步骤和 BOM 应该按你的条件变化。

## 复制这段给你的 Agent

> 请作为我的 DIY 制作助手，先阅读 https://mayf3.github.io/diy-lab/projects/ ，选择项目后打开它的 **Agent 执行版**；例如哈基米机是 https://mayf3.github.io/diy-lab/projects/hachimodock/agent-track/ 。请优先读取真实的项目源仓库、发布记录、零件规格书和机器可读工作流。你负责检索、比对、建立物料表、核算含运费预算、检查 CAD 文件与兼容性、准备切片和记录证据；不要让我替你逐项阅读 GitHub 或判断 PCB。若你的工具没有权限，准确说明缺的是什么，只向我索取最少必要的截图、文件或设备信息。请清楚区分“查到的来源事实”“你的推断”“数字模拟”“我亲手做过的测试”。在商品型号、接口或儿童/用电风险不清时停止下单，不要宣称已经验证。实物打印、焊接、插线、测量、付款等步骤需要我动手或授权。每一关只告诉我：现在要做什么、你已经完成什么、我必须做什么、怎么判断成功、失败时下一步怎么办。

## 三条路线：按资源选，不按读者身份选

| 你目前的条件 | 建议路径 | 你需要做的事 |
| --- | --- | --- |
| **自己有 3D 打印机** | Agent 检查兼容性和切片 → 你打印试件 → 你测量 | 告诉 Agent 打印机、喷嘴与耗材；按设备原厂安全说明打印 |
| **没有打印机** | Agent 整理打印文件、精度和服务规格 → 找合适代打印 → 验收 | 选服务、下单、收件、试装；成本与运费进入总 BOM |
| **有朋友/创客空间可借用** | Agent 给场地设备准备对应切片及测试清单 | 先确认设备和材料再操作，不复制特定机器的参数 |

电子制作也一样：**会焊接**可以自己按安全流程焊；**不会焊接**先练习或咨询有能力的协助者，不能假装找个 AI 就省略真实焊接。若某项技术必须亲手操作，说明原因而不是把它伪装成“AI 自动完成”。

## 怎么读一个项目？

- **先看人类制作版**：每一步只做有意义的动作，链接可展开完整操作。
- **AI 读 Agent 执行版**：包含依赖、输入、任务委托、输出、证据与失败分支。AI 应主动完成公开资料调查，不应把“去看 GitHub”原样转交给你。
- **按需看深入教程**：遇到真实接线、结构配合或故障时再看具体细节；新手不必先看完全部工程文档。
- **实测记录不是学习打卡**：网页上的勾选仅保存在你的浏览器，不能代表硬件实际通过测试。

## 什么时候必须停下来让人确认？

**付款、给实物通电、烙铁/刀具/热熔操作、涉及儿童使用安全、拆装敏感设备、不可逆固件写入**都是风险较高的动作。Agent 可以准备、核对和解释，但不能用公开网页或模型推断取代实物证据、授权及有能力的安全操作。
