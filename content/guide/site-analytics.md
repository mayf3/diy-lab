# Mayf3 站点统计｜site-analytics 架构与接入规范（v0.1）

> 状态：**已采纳**。本页是 Maker Lab 侧对三站统计架构的权威记录；`site-analytics` 包本身由 **Learn Agent** 维护（建议路径 `packages/site-analytics/`，最终以其仓库为准），本仓**不建设、不复制、不修改**该包的任何产物。
> 关联：[Mayf3 Design System](/guide/design-system/)（同为三站统一基建）。

## 一、架构决策：一份公共模块 + 各站薄接入

埋点逻辑**不允许**各网站分别实现一套统计框架。唯一实现位于 `site-analytics` 包，各站只做薄接入。

**公共模块只负责五件事**（职责白名单，超出即越界）：

1. 初始化与**生产环境门禁**（非生产域名不发数据）；
2. **退出统计**（用户退出/拒绝时静默停用，含尊重浏览器 DNT 类信号）；
3. **事件/字段白名单**（白名单外的事件与字段一律丢弃，不透传）；
4. 自动 pageview 与自定义事件的**统一隐私处理**（去 PII、去 query/fragment 等统一规则）；
5. **安全上报接口**（对统计工具的受控封装）。

**明确不重做**（优先使用统计工具已有能力）：访客标识、路由采集、传输队列、看板。包也不依赖课程业务、React 或 Learn 页面代码——保持与任何单一站点解耦。

## 二、发布物要求（由包维护方随每个版本交付）

- 同一份源码产出 **ESM** 与**浏览器脚本**两种产物；**按固定版本发布**，不做线上 latest。
- 每个版本附：**事件协议**、**来源提交 SHA**、**文件哈希**、**测试结果**、**兼容的统计工具版本**。
- 公共问题回到唯一源码修复 → 发新版本 → 各站**显式升级**；禁止任何人原地改 vendor 产物。

## 三、各站只做三件事

1. 本站配置：`siteId`、域名、环境、版本（消费固定版本产物）；
2. 在**真实业务动作发生处**调用统一接口（不做与动作无关的埋点）；
3. 本站浏览器验收：页面导航、事件触发、去重。

npm 项目按固定版本消费包；纯静态站（Map、Maker Lab）直接消费**同版本浏览器产物**。不为统计增加业务后端，不改变各站现有技术栈。

## 四、禁令（对所有站点与会话生效）

- 各站**禁止直接读取其他仓库工作目录**；
- 禁止修改 vendor 中的公共产物；
- 线上禁用会被原地覆盖的 `latest` 脚本；
- 公共缺陷不在站点侧打补丁，走 §二 的回源-发版-升级流程。

## 五、推广顺序

1. **先在 Map 与 Learn 两类不同网站验证同一模块**（静态杂志型 vs React 应用型），通过后发布；
2. 通过后接入其他公开网站（**Maker Lab 属于这一波**）；
3. **内部播客制作/审听工作台不接入**（非公开站点）。

## 六、Maker Lab 现状盘点（2026-11-12）

| 项 | 结果 |
| --- | --- |
| 仓库内统计代码 | **无**（grep gtag/umami/plausible/matomo/posthog/analytics 全空；`assets/main.js` 首行注释明确 "No analytics, account, network request, or backend"） |
| 线上部署（diy-lab.mayf3.com） | **无**任何统计脚本 |
| 可复用既有实现 | **无** → 不自行建设，等待 site-analytics 包 v1 在 Map/Learn 验证发布后接入 |

注意：接入时须同步更新 `assets/main.js` 首行注释，如实反映"有统计上报"这一网络行为，不得保留过期声明。

## 七、Maker Lab 接入规格（包 v1 发布并通过 Map/Learn 验证后执行）

- **消费方式**：静态站消费固定版本浏览器产物 → `assets/vendor/site-analytics-<固定版本>.js`，随构建进 dist；**禁用 latest**；在本文档登记版本、来源提交与文件哈希。
- **配置**：`siteId: maker-lab`（最终值由包维护方分配）；环境门禁=仅生产域名 `diy-lab.mayf3.com`；本地 `127.0.0.1` 与 GitHub Pages 预览不发送。
- **事件白名单（提案，接入前与包维护方对齐）**：
  - 自动 pageview（MPA 每页加载一次；本站无 SPA 路由，去重风险低）；
  - `bom_download`（字段：project=hachimodock|christmas-magic-tent）——BOM CSV 下载点击；
  - `concept_full_open`——帐篷效果图高清原图放大；
  - `tutorial_cta_click`（字段：target）——项目页主 CTA 点击。
- **隐私红线**：**学习进度勾选、搜索词、本地 localStorage 状态永不上传**（站点承诺"进度只保存在本机"）；事件 payload 不含 query/fragment/文件名以外的路径信息；无 cookie。
- **验收清单（接入 PR 时逐项执行）**：① 每个页面导航恰好一条 pageview（无重复触发）；② 自定义事件仅由真实动作触发一次；③ `127.0.0.1` 与预览环境零请求；④ 退出统计/DNT 生效；⑤ 非 whitelist 事件被丢弃（抓包确认）；⑥ 移动端 Safari 与桌面 Chrome 双端通过。
