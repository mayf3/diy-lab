# Mayf3 Design System｜Learn 海景视觉（规范 v0.4）

> 2026-11-13：用户明确以 Learn 的背景与画风为共同基准。视觉定义已提取到独立 `mayf3-visual-system` 仓库；本站固定消费视觉包 **0.1.0**，具体路径与清单哈希见仓库根的 `visual-system.lock.json`。此处是 Maker Lab 接入记录，不再维护另一份跨站令牌权威。
>
> 本地源码接入与线上发布分开验收；本次记录不代表网站已发布。

## 一、共同风格与各站职责

适用 Learn、Podcast Map、Maker Lab（本站）与本机播客工作台。颜色、背景、字体层级、卡片和基础控件保持共同风格；课程、地图导航、DIY 验收、音频编辑各自保留内容与布局。

基准为 Learn 的青雾海景、浅纸面、墨绿色文字、苔绿操作色、赭色强调。阅读区使用近似不透明纸面；工具页保留清晰的状态和信息密度。

## 二、固定版本视觉包

本站从 `assets/vendor/mayf3-visual/0.1.0/seaside.css` 加载主题，背景图与 CSS 位于同目录，嵌套页面、GitHub Pages 子路径和离线页面都用相对链接。

| 用途 | 共享变量 | 0.1.0 基准 |
| --- | --- | --- |
| 背景纸色 | `--mf-paper` | `#f0f4f4` |
| 卡片 | `--mf-card` | `#f7fbfb` |
| 文字 | `--mf-ink` | `#27302e` |
| 次级文字 | `--mf-ink-muted` | `#6b675f` |
| 主要操作 | `--mf-moss` | `#64735a` |
| 强调 | `--mf-accent` | `#bf704e` |
| 边线与圆角 | `--mf-border` / `--mf-radius` | 墨色 12% / 2px |

海景沿用 Learn 原图；桌面遮罩 .60→.75，720px 以下 .72→.85。标题衬线、正文中文无衬线、编号与时间等宽。无新增字体网络请求、阴影或发光效果。

上表用于说明已锁定版本，实际值以共享包为准。`assets/style.css` 仅把本站变量映射到 `--mf-*` 并维护本地组件；不再复制一套基础背景。

## 三、更新与 agent 规范

消费包自带 `SKILL.md`，维护页面前先读它和根锁文件。用共享仓库的 `tools/sync-consumer.py` 同步固定新版本；加 `--check` 核验当前副本。已有版本不可原地改写。

共同风格调整在共享仓库修改并发布新版本；本站显式升级。图表、错误提示、真实作品图、来源标签保留各自语义，不由主题统一改色。

本站仍只需 Python 和 Mistune；不增加网站服务、前端框架或统计脚本，不跨仓读取运行时文件。

## 四、验收与历史

运行 `python3 scripts/check.py`、`python3 scripts/build.py` 和 `python3 scripts/verify_site.py`。检查桌面与390px首页、项目详情、搜索、手机导航和键盘焦点；使用源码包不依赖其他站点在线。

v0.1–v0.3 曾以 Map 暖纸白/海蓝青为主要参考，并在本站增加海景。v0.4 按用户最新要求以 Learn 实际视觉为基准，并将共享权威迁出本站；旧版本历史保留在 Git。
