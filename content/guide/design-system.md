# Mayf3 Design System｜设计母体 v0.1（基线）

> 状态：**方向已采纳，实现未开始**。本文档是三站统一的权威决策记录；改动这里前先看[技术决策边界](#六边界与不做清单)。
> 适用：Learning Lab（learn.mayf3.com）· Podcast Map（map.mayf3.com）· Maker Lab（diy-lab.mayf3.com）。

## 一、核心原则：一个设计母体，三种内容表达

三个站出自同一创作者，要一眼可辨"同一家人"，又要立刻分清功能。统一的是**设计规则**（色板、字体、排版尺度、组件规范、交互与无障碍），不统一的是**内容组织方式**与**业务逻辑**（课程进度、播放、搜索、DIY 验收状态一律不动）。

| 网站 | 定位 | 视觉隐喻 | 保留特色 |
| --- | --- | --- | --- |
| Learning Lab | 系统学习、交互教程 | 能动起来的教材 | 学习路径、视频、练习与进度；海景/青雾气质 |
| Podcast Map | 知识发现、播客探索 | 有索引的知识杂志 | 问题导航、主题关联、收听路线；编辑式排版（作为母版基础） |
| Maker Lab | 动手创作、实践记录 | 精良的制作手册 | 项目展示、步骤、材料与验收；功能架构 |

审美立场：安静、清晰、温暖、精致的知识工作室。**不做**深色背景 + 霓虹渐变 + 发光卡片 + 无意义动画的"AI 产品风"。

## 二、设计令牌（v0.2 — 2026-11-12 按 learn/map 实测值校准）

> **v0.1 → v0.2 变更原因**：v0.1 的墨绿主色（#326F67）落地后发现与 learn/map 的实际画风仍有差距——两站实测主色是**低饱和海蓝青/灰绿**，且都有**青雾空气感背景**。v0.2 直接取两站 CSS 实测值校准（map `--green:#1e7898`、`--bg:#f9f7f1`；learn `--mist:#eef4f4`、陶土橙两站一致）。

```css
:root {
  /* 色板（v0.2，来源：map/learn 线上 CSS 实测） */
  --mds-bg: #f9f7f1;         /* 暖纸白：页面底色（map --bg） */
  --mds-paper: #fcfbf6;      /* 暖白：卡片/面板（map --paper） */
  --mds-mist: #edf3f5;       /* 青雾：背景渐变与悬停底（map --soft / learn --mist） */
  --mds-ink: #162e3b;        /* 深海墨蓝：正文与标题（map --ink） */
  --mds-teal: #1e7898;       /* 海蓝青：链接/主操作（map --green） */
  --mds-sage: #829477;       /* 灰绿：次级点缀（learn --leaf） */
  --mds-clay: #ad6349;       /* 陶土橙：强调/警示点缀（map --accent） */

  /* 排版 */
  --mds-font-serif: "Songti SC", "STSong", "Noto Serif SC", "Source Han Serif SC", serif; /* 中文大标题 */
  --mds-font-sans: -apple-system, "PingFang SC", "Noto Sans SC", sans-serif; /* 正文 */
  --mds-font-mono: "SF Mono", "JetBrains Mono", Consolas, monospace; /* 编号/元数据 */
  --mds-body-size: 16.5px;
  --mds-body-lh: 1.8;
  --mds-measure: 720px;      /* 阅读栏宽度 */

  /* 形状与层级：内容层级和留白区分，不靠堆容器 */
  --mds-radius: 4px;
  --mds-border: 1px solid rgba(22, 46, 59, 0.13); /* map --line */
  --mds-shadow: none;        /* 默认无阴影；弹出层可用极浅 0 12px 40px rgba(22,46,59,.18) */
}
```

**空气感规则（v0.3 更新）**：三站共用同一幅**海景家族背景图**（`seaside.jpg`，与 learn/map 同源素材，约 200KB）；实现 = 半透明雾罩渐变叠在照片上，`background-attachment: fixed`（移动端回退 scroll），照片从页底透出、阅读区始终有 ≥60% 雾罩保证可读性。顶栏与侧栏**透明融入背景**（顶栏保留模糊以保证可读），不再用实心白盒。**v0.3 变更原因**：v0.2 仅用 CSS 渐变，缺照片纹理，与 learn/map 并排时仍不像一族。

规则：卡片细边框 + 4px 圆角 + 默认无阴影；交互只做轻微颜色变化（无浮起/缩放/发光）；所有交互元素统一键盘焦点样式（2px 海蓝青 outline）。

## 三、现状差距（2026-11 审计）

| 维度 | Learning Lab | Podcast Map | Maker Lab（本站） |
| --- | --- | --- | --- |
| 底色 | 青灰浅雾 | 暖白浅海蓝 | 灰白浅绿 |
| 标题 | 衬线 | 宋体风格 | 粗体无衬线 |
| 卡片圆角 | ~2px | ~2–3px | 12–16px（需收敛） |
| 阴影 | 无 | 无 | 多处（需移除） |
| 气质 | 课程文档 | 杂志 | SaaS 平台（需调整） |

改造方向：以 Podcast Map 的编辑式排版为母版基础，保留 Learning Lab 的青雾气质；**Maker Lab 视觉向前两者靠拢，功能架构不动**。

## 四、推进顺序（每步一个独立 PR + 视觉验收）

1. **设计基线**：三站桌面/移动端首页与典型内容页截图归档；本文档即共同规范 v0.1。
2. **先改 Maker Lab 首页**（差异最大）：收敛大圆角、移除阴影、去 SaaS 卡片感 → 安静的作品展示；保留全部功能。验收：改版前后截图逐屏对比 + 无障碍焦点检查 + `check.py/build.py/verify_site.py` 全绿。
3. **统一头部与阅读体验**：三站字体、按钮、链接、文字尺度、导航细节、页脚；加入克制的跨站入口（三站互链）。
4. **品牌与维护**：固定令牌版本号（本文档 § 二即 v0.1）；视觉回归检查纳入各站 CI（截图对比）；防止三个 Agent 会话各改各的。

## 五、各站落地方式

不迁移框架。共享的是设计变量与组件规范，不是代码：

- **Maker Lab（本仓库）**：`assets/style.css` 引入上述令牌并逐步替换硬编码值；`build.py` 侧不改业务逻辑。
- **Learning Lab / Podcast Map**：分属各自仓库与会话维护（本仓库工作约束不跨仓修改）；由各自会话读取本文档（或提取到独立 `design-system` 仓库）后自行落地。

## 六、边界与不做清单

- 不改各站内容组织方式与 URL 结构。
- 不改业务逻辑：进度存储、搜索、视频播放、勾选验收、BOM 门禁。
- 不引入新框架/依赖来"实现统一"（Maker Lab 仍只依赖 Python + Mistune）。
- 令牌值改动必须先改本文档并升版本号，再改 CSS——文档先行，避免漂移。
- 视觉改版未做逐屏验收前，不得声称"已完成统一"。
