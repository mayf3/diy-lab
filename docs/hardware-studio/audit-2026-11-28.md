## 4. 治理决策

- 版本四元组一致性、状态机（M3）、证据三态已有 prose 合同（models-r1.md / factory-delivery-plan / registry）；**PR-A 将其落为机器校验**（check_project.py）；Lean 形式化仅在 PR-B 出现跨工具不变量证明需求时评估，不为界面文案增加证明负担。
